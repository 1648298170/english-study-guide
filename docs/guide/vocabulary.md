## 4.1 词汇量与能力的关系（研究数据）

| 词汇量（词族）     | 覆盖率               | 意味着什么                   |
| ----------- | ----------------- | ----------------------- |
| 2,000       | 书面 ~80% / 口语 ~96% | 日常口语的骨架，最优先搞定           |
| 3,000       | 播客 ~96%           | 播客成为可懂输入，听力进入快车道        |
| 4,000~5,000 | 小说/报刊 ~95%        | 可猜词泛读的最低门槛              |
| 6,000~7,000 | 口语 98%            | 母语级舒适听力                 |
| 8,000~9,000 | 书面 98%            | 母语级舒适阅读（受教育母语者约 20,000） |

**98% 覆盖 = 无辅助舒适理解；95% = 能猜词理解的底线**（Nation 2006）。

## 4.2 执行策略

1. **前 2,000 词靠刷**：Anki + 高频卡组，集中 6~8 个月。注意这是"**有语境的刷**"——4000 EEW 卡组自带音频+图片+例句，刷的是"词在句子里怎么用"，不是干背字母串。这是全场 ROI 最高的投入
2. **3,000 起靠挖矿**：只背自己输入中遇到过的词（句子挖矿），Anki 卡带原文例句
3. **5,000 起靠语境**：词根词缀（系统方法与资源见 4.4）+ 语境猜词 + 领域专精，不再无差别刷表
4. **永远英英优先**：B1 起逐步换用英文释义卡组（COCA deck），打破"英文→中文→理解"的翻译回路
5. **每天 Anki 不超过 40 分钟**：SRS 建立的是"认识"，"会用"必须靠大量阅读听力——超时刷卡是伪勤奋

## 4.4 词根词缀：把"死记"变成"理解记忆"

**为什么需要它**：英语词汇分两个世界。最高频的 ~2,000 词多是盎格鲁-撒克逊本族语——短小、不可拆（the / go / get / work），这部分只能靠高频重复 + 语境硬啃；而 3,000 词以上的中低频词（尤其学术、科技、正式文体）大量来自**拉丁/希腊语源，可拆解**。掌握约 300 个常见词根 + ~100 个前后缀，等于拿到数万中低频词的"偏旁部首"——就像认汉字：会"氵"就能猜出"江、河、湖"的类别。

一个词根族长什么样：

```
spect = 看（拉丁 specere）
→ inspect   检查（in- 向内 + 看）
→ respect   尊敬（re- 反复 + 看 → 反复看 → 重视）
→ prospect  前景（pro- 向前 + 看 → 看到的未来）
→ spectator 观众（-ator 人 → 看的人）
→ perspective 视角（per- 穿过 + 看）
```

背 1 个词根 ≈ 理解 10+ 个派生词，而且**理解过的词猜得出来就忘不掉**——这是死记硬背永远给不了的保持率。

**启动时机**（学早了是浪费）：

- 阶段 1~3（<3,000 词）：**不学**。高频词里拉丁词源占比低，词根法收益小
- 阶段 4（B2，约 4,500 词）：**启动**。先攻最常见的 50~80 个词根族（spect / port / duct / struct / form / vis / dict / ject…）
- 阶段 5+（C1）：**系统化**。用完整教材过全量词根体系，配合领域词汇

**方法三原则**：

1. **词根永远绑定派生词学**——背"spect = 看"本身没有意义，记住 inspect/respect/prospect 这一串才有意义。词根是记忆钩子与猜词工具，不是学习目标
2. **Anki 卡片加"词根拆解"字段**——挖矿遇到可拆的词，先查 Etymonline 词源，把拆解写进卡片（如 *invisible = in-(不) + vis(看) + -ible(可)*），每次复习都是一次结构强化
3. **词根只用于猜词，不用于造词**——能推测生词大意 ≠ 能自己拼新词（反推常造出不存在的词）
