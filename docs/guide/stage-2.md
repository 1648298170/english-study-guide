*属于[第 3 章 · 阶段详解](/guide/roadmap) · 上一阶段：[阶段 1 · 地基期](/guide/stage-1) · 下一阶段：[阶段 3 · 成长期](/guide/stage-3)*

**阶段定位**：词汇翻倍到 2,000，启动分级阅读引擎，开始影子跟读。时间配比：显性 25%，精读精听 50%，泛读泛听 25%。

> 🎓 **站内课程**：本阶段语法主线 = [A2 课程 · 积累期](/course/a2/)（9 课，现在进行时→介词）。[词根词缀课](/course/roots/)从本阶段起可系统刷（A2 词汇打底后收益开始显现）。

| 模块         | 具体安排                                                                                                                                                     |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **词汇**     | 目标累计 2,000 词（前 2,000 高频词 = 覆盖书面文本约 80%、日常口语约 96%——这是性价比最高的一批词）。Anki 每日 30~40 分钟                                                                          |
| **语法**     | 序列：现在进行时（对比一般现在时）→ 一般过去时（规则→不规则）→ will/be going to → 频率副词 → 可数不可数 + much/many/some/any → 比较级最高级 → 时间地点介词。工具：红宝书后半 + 《English Grammar in Use（蓝宝书）》前 30 单元 |
| **语法主线教材** | 《新概念英语 2》开始：每周精学 2 课（共 96 课约 1 年完成）。用法：听录音→跟读→背课文→做课后题，配 B 站名师讲解视频。**注意：新概念只作语法与句型骨架，不当唯一教材**（内容成书于 1967 年，话题陈旧是其硬伤，但语法编排和语料质量仍是中文世界最优）                  |
| **听力**     | **English Pod**（初级~中级对话，中文社区口碑第一的精听教材，每日英语听力内有）每周精听 3 集 + **VOA 慢速**泛听每天 20 分钟 + BBC 6 Minute English 每周 2 集                                             |
| **阅读**     | **启动分级阅读（本阶段最重要的事）**：《书虫》入门级~Level 2（250~600 核心词），每周 1 本（每本约 1h），读完听一遍配套音频。选 95% 以上词认识级别的书                                                               |
| **口语**     | **开始影子跟读（Shadowing）**：材料用 English Pod / 新概念 2 音频，延迟 0.5~1 秒同步跟说，每天 15~20 分钟。2025 年系统综述证实跟读对听力理解、音素感知、发音三项均有效                                             |
| **写作**     | 无独立写作；每周用本阶段语法点造 10 个句子                                                                                                                                  |

**每周模板（约 12h）**：Anki 7×35min ＋ 新概念 2×45min ＋ 蓝宝书 3×30min ＋ English Pod 精听 3×30min ＋ 泛听 7×20min ＋ 书虫 1 本/周 ＋ 跟读 6×20min

**毕业标准**：

- [ ] 累计 2,000 词
- [ ] English Pod Elementary 级对话不看文稿听懂 ≥80%
- [ ] 书虫 Level 2 读起来不查词也流畅
- [ ] 能用一般现在/过去/将来时描述自己的一天、上周末、周末计划（各 1 分钟，录音自评）
