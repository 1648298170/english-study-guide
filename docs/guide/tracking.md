## 9.1 三层检测体系

| 频率  | 检测                      | 工具                                                       |
| --- | ----------------------- | -------------------------------------------------------- |
| 每天  | 完成打卡（Anki 新词/复习数、输入分钟数） | 学习日志                                                     |
| 每月  | 词汇抽测 + 录音 1 分钟自评（对比上月）  | Anki 统计 + 手机录音                                           |
| 每阶段 | 毕业标准清单逐项核对              | 本文档[第 3 章](/guide/stage-0)                                                 |
| 可选  | 客观水平考试                  | 剑桥 A2 Key → B1 Preliminary → B2 First → C1 Advanced（或雅思） |

## 9.2 学习日志（建议放 `data/` 目录）

```
data/
├── log.md          # 每日一行: 日期 | Anki(新+复) | 输入(分钟) | 输出(分钟) | 备注
├── vocab.csv       # 词汇量月度记录: 日期, 累计词数
├── recordings/     # 每月一段 1 分钟口语录音, 命名: 2026-09.md 对应 2026-09.mp3
└── reviews/        # 每阶段毕业自评: 逐项打勾 + 反思
```

**每月回听上月录音**——进步的声音是你最好的燃料。

## 9.3 调整原则

- 连续 2 周未达标 → 先降强度（砍 30%），不断中断——**持续性 > 强度**
- 材料 70% 以下看不懂 → 降级材料（可懂输入是铁律）
- 某技能明显落后（如 B2 了还不敢开口）→ 阶段内加练该技能，不整体降级
- 每半年通读本文档一次，校准自己所处阶段
