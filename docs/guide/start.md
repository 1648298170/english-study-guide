> 面向中国成人自学者的英语学习完整方案 · 基于二语习得（SLA）科学研究 · 2026 版
>
> **你是谁**：零基础、母语中文、在中国大陆、想自学英语到精通
> **这是什么**：一份多年期路线图（框架）+ 十三门可跟学的中文课程 + 发音点读系统——框架管"学多久、何时进阶"，课程管"每一个知识点学懂"
> **总时长预期**：每天 1.5~2 小时，约 **2 年到 B2（高级交流）**，**3~4 年到 C1（精通入门）**——这是诚实的数据，不是营销话术

## 本站有什么

| 板块 | 内容 | 位置 |
|---|---|---|
| **框架（地图）** | 七个学习阶段的目标/工具/每周模板/毕业标准 | [总览路线图](/guide/roadmap) · [阶段详解](/guide/stage-0) |
| **课程（车）** | 13 门中文课程，112+ 课页，全部带练习与答案 | [课程总览](/course/) |
| **发音系统** | 单词 🔊 点读 + 音标 ▶ 音素播放（启蒙/词根/词性课） | 课程页内自动出现 |

## 课程怎么排（当前学习顺序）

```
① 启蒙课（音标与拼读，1~2 周）
② 词根词缀课（记忆技巧；前 2 课零基础友好，后面卡住就跳）
③ 学习阶段 · 语法主线（词性课 → A1 → A2 → B1 → B2 → C1，约 2~3 年）
④ 技能四件套（B1 后按需并行，先读后写）：
   句子拆解课（长难句+中译英） → 语法详解课（考点查漏）
   → 阅读理解课（题型策略） → 写作课（从句子到文章）
```

**入门动作**：零基础 → 直接从[启蒙课第 1 课](/course/stage0/01-alphabet)开始；有点基础 → 做[课程总览](/course/)里的阶段对照，插入对应课程。

## 六条使用原则

1. **先读[路线图](/guide/roadmap)和[五大核心原则](/guide/principles)**（15 分钟）——知道"为什么"才能坚持"怎么做"
2. **课程负责学懂，框架负责进度**：白天按框架的每周模板执行，"学教材"时段换成当前课程；课程毕业标准即框架阶段毕业标准
3. **只执行当前阶段**。不要提前研究 C1 阶段的方法，现在用不上
4. **每阶段结束做毕业测试**（[阶段详解](/guide/stage-0)每阶段末尾有明确标准），达标才进下一阶段
5. 工具清单在[资源工具箱](/guide/toolbox)按需取用；**大陆无墙完整方案**见[无障碍专页](/guide/china)
6. 在仓库 `data/` 目录记录学习日志（格式见[检测与记录](/guide/tracking)）——每月回听录音，进步的声音是最好的燃料
