---
title: 阶段 1：地基期（A1 · 2~3 个月 · 累计 150h）
---

*属于[第 3 章 · 阶段详解](/guide/roadmap) · 上一阶段：[阶段 0 · 启蒙期](/guide/stage-0) · 下一阶段：[阶段 2 · 积累期](/guide/stage-2)*

**阶段定位**：建立第一批词汇和基本句型，让英语"不再可怕"。时间配比：显性学习 40%，精读精听 60%，暂不输出。

| 模块     | 具体安排                                                                                                                                             |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **词汇** | 目标 1,000 高频词。工具：Anki「4000 Essential English Words」卡组（选英中双语版）或 不背单词。每天 30 分钟新词+复习                                                                 |
| **语法** | 主线 A（见[第 5 章](/guide/grammar)阶段 1 序列）：be 动词 → 人称/物主代词 → 名词单复数 → a/an → there is/are → 一般现在时 → can → 一般疑问/特殊疑问句。工具：《Essential Grammar in Use（红宝书）》前 20 单元，每单元 20 分钟 |
| **听力** | VOA Learning English「Let's Learn English Level 1」视频课（每日英语听力 App 内）+ 多邻国 15 分钟/天（仅作习惯养成器，3 个月后停用）。听不懂就看文稿，看不懂就查词——这是"精听"不是 cheating               |
| **阅读** | 暂不单独安排；多邻国和语法书的例句就是阅读量                                                                                                                           |
| **口语** | 只做一件事：**跟读（Read aloud）**。把听过的 VOA 句子大声朗读模仿，每天 10 分钟                                                                                              |
| **写作** | 无。抄写好句子即可                                                                                                                                        |

**每周模板（约 12h）**：词汇 7×30min ＋ 语法 4×30min ＋ VOA 精听 6×30min ＋ 多邻国 7×15min ＋ 跟读 5×15min

**毕业标准**：

- [ ] Anki 认识 1,000 词（成熟卡 ≥80% 正确率）
- [ ] 慢速清晰的问候、数字、时间、自我介绍能听懂
- [ ] 能做 30 秒自我介绍（姓名/来自/职业/爱好）
- [ ] 红宝书前 20 单元练习正确率 ≥85%
