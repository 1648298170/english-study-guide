---
title: 语法学习顺序
---

> 依据：二语习得"自然顺序假说"与"可教性假说"（Pienemann）——习得阶段不可跳跃，按可习得顺序教学效果显著优于乱序。第三人称单数 -s 等形态素习得极晚属正常现象，**别在 A1/A2 阶段死磕它**。

| 阶段     | 语法主题（按此顺序）                                                                                                |
| ------ | --------------------------------------------------------------------------------------------------------- |
| **A1** | be 动词 → 人称/物主代词 → 名词单复数 → a/an → there is/are → 一般现在时 → can → 一般/特殊疑问句 → 数字/时间/星期                         |
| **A2** | 现在进行时（vs 一般现在时）→ 一般过去时（规则→不规则）→ will / be going to → 频率副词 → 可数不可数 + much/many/some/any → 比较级/最高级 → 时间地点介词 |
| **B1** | **现在完成时（重点+难点）** → 过去进行时 → 条件句一/二 → should/must/have to → 连词 → 不定式 vs 动名词 → 短语动词入门 → 定语从句                 |
| **B2** | 过去完成时 → 第三/混合虚拟 → 间接引语 → 被动语态 → 推测情态 → 冠词系统精讲 → 高级动名词/不定式模式                                               |
| **C1** | 倒装 → 分裂句 → 省略/替代 → 名词化 → 语域控制 → hedging 与话语标记                                                             |

**执行原则**：语法书当"字典+预习工具"用——每次 20~30 分钟学一小节，然后**去输入里验证**（在读/听中标记刚学的结构），而不是刷完一本再开始阅读。
