title: 阶段 3：成长期（B1 · 8~12 个月 · 累计 600h）
---

*属于[第 3 章 · 阶段详解](/guide/roadmap) · 上一阶段：[阶段 2 · 积累期](/guide/stage-2) · 下一阶段：[阶段 4 · 突破期](/guide/stage-4)*

**阶段定位**：从"学英语"转向"用英语"。分级阅读升级为泛读引擎，播客成为主食，**开始开口**。时间配比：显性 15%，精读精听 50%，泛读泛听 25%，输出 10%。

| 模块         | 具体安排                                                                                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **词汇**     | 目标累计 3,000 词（此时已覆盖播客约 96% 的词——播客正式成为可懂输入）。3,000 之后频率词表边际收益递减，开始执行"句子挖矿"：从自己的阅读/听力中挑生词做 Anki 卡                                                          |
| **语法**     | 序列：**现在完成时（A2→B1 最大坎，慢慢来）** → 过去进行时 → 条件句第一/第二 → should/must/have to → 连词（because/although/however）→ 不定式 vs 动名词 → 短语动词入门 → 定语从句。工具：蓝宝书剩余单元             |
| **听力**     | 主食：**All Ears English**（美音真实语速，每周 5 更）或 **ESLPod**；进阶加 **VOA 常速**。策略：每集先裸听→再对照文稿精听→存生词。每周精听 3 集 + 泛听不限量（做饭通勤都放着）                                       |
| **阅读**     | 书虫 Level 3~5，每周 1~2 本；加 News in Levels（同一条新闻三档难度）每天 1 篇。**泛读开始大于精读**                                                                                   |
| **口语**     | 三级火箭：① 继续 Shadowing（材料升级为 All Ears English / 老友记片段）② **AI 口语**：可栗口语/Speak/流利说，每周 3~4 次×15 分钟情景对话 ③ **首次真人课**：italki 社区教师（$5~10/节）每周 1 节，从"自我介绍+日常话题"开始 |
| **写作**     | 每周写 3~5 句日记→逐渐到 100 词短文；写完让 ChatGPT/AI 批改（或发 HelloTalk 请语伴纠错）                                                                                          |
| **发音（可选）** | 若自觉发音是短板，上 **ELSA Speak**（音素级 AI 纠音，国人最常用）每天 10 分钟                                                                                                     |

**每周模板（约 14h）**：Anki 7×30min ＋ 蓝宝书 2×30min ＋ 精听 3×40min ＋ 泛听 7×30min ＋ 泛读 5×40min ＋ Shadowing 5×20min ＋ AI 口语 3×15min ＋ 真人课 1 节 ＋ 写作 1×20min

**毕业标准**：

- [ ] 累计 3,000 词
- [ ] VOA 常速新闻听懂大意（能复述 who/what/when/where）
- [ ] All Ears English 无文稿听懂 ≥70%
- [ ] 与 italki 外教进行 15 分钟日常对话（允许卡顿、查词）
- [ ] 书虫 Level 5 / Penguin Readers Level 5 流畅阅读
- [ ] （可选验证）剑桥 B1 Preliminary 模拟题达到"合格"档
