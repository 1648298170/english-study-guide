*属于[第 3 章 · 阶段详解](/guide/roadmap) · 下一阶段：[阶段 1 · 地基期](/guide/stage-1)*

**唯一目标**：解决"发音+工具"两件事，正式开学。

| 模块    | 内容                                                                          |
| ----- | --------------------------------------------------------------------------- |
| 音标与发音 | 学完自然拼读（Phonics）+ 国际音标（IPA）。推荐 B 站「英语兔」音标课（免费、公认第一站）。目标：看到单词能大致读出音，听到音能大致拼出词 |
| 工具就绪  | 装好：Anki（电脑/安卓免费）+ 一款中文背词 App（不背单词/百词斩）+ 每日英语听力 + 多邻国                        |
| 心理建设  | 读完本文档[第 2 章](/guide/principles)；准备一个学习日志；设定每天固定学习时段（建议 ≥1.5h，可拆分）                                |

**毕业标准**：48 个音素发音过关（能对照音标读出任意单词）、工具全部就位、连续 7 天完成每日学习。
