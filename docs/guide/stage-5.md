*属于[第 3 章 · 阶段详解](/guide/roadmap) · 上一阶段：[阶段 4 · 突破期](/guide/stage-4) · 下一阶段：[阶段 6 · 精通期](/guide/stage-6)*

**阶段定位**：从"能用"到"精准自然"。去掉字幕和词典拐杖，输出追求准确与地道。

> 🎓 **站内课程**：本阶段语法主线 = [C1 课程 · 精进期](/course/c1/)（7 课，倒装→hedging）。技能课收尾：[写作课](/course/writing/)图表作文与[阅读理解课](/course/reading/)泛读计划在本阶段完成；[词根词缀课](/course/roots/)系统化过全量体系。时间配比：显性 10%，精读精听 25%，泛读泛听 35%，输出 30%。

| 模块     | 具体安排                                                                                                                        |
| ------ | --------------------------------------------------------------------------------------------------------------------------- |
| **词汇** | 累计 6,000~8,000 接受性词汇（达到 98% 覆盖的听力学需：6,000~7,000 词族）。策略转向：**词根体系化**（用《英语词根与单词的说文解字》或 Vocabulary Builder 过全量体系，见[4.4](/guide/vocabulary)）+ 语境猜词 + 领域词汇（按你的职业/兴趣建专项卡组：商业/科技/法律…）。低频词不再刷表，从大量输入中自然积累 |
| **语法** | C1 级修辞语法：倒装、分裂句（cleft）、省略与替代、名词化、语域控制（正式/非正式切换）、模糊限制语（hedging）与话语标记。绿宝书 + 《Oxford Guide to Effective Writing and Speaking》  |
| **听力** | 去字幕化：影视从双语→纯英文字幕→无字幕三步走。播客主食：The Daily（NYT）/ The Economist 编辑播客 / 行业播客。**泛听：任何愿意听的英文音频，不限量**                                |
| **阅读** | 外刊精读（The Economist/Atlantic 每周 2 篇精读+不限量泛读）；原版书每月 1~2 本，类型扩展到非虚构；开始读自己领域的英文资料/文档                                            |
| **口语** | 真人课聚焦**纠错与精进**（要求教师逐句记录你的错误并复盘）；尝试**语言交换**（HelloTalk/Tandem）建立免费长期对话伙伴；若工作可用英语，主动争取英文会议/邮件场景                                |
| **写作** | 每周 300~500 词；体裁扩展（议论文/邮件/报告）；开始学习英文文体（风格）——推荐《On Writing Well》                                                              |

**毕业标准**：

- [ ] 累计 7,000+ 接受性词汇
- [ ] 无字幕看懂电影/纪录片 ≥90%
- [ ] The Daily / The Economist 音频无文稿听懂 ≥90%
- [ ] 外刊精读顺畅（每小时 ≥800 词且能做摘要）
- [ ] 就任意熟悉话题即席表达 10 分钟，逻辑连贯、错误不干扰理解
- [ ] （验证）雅思 7.5+ / 剑桥 C1 Advanced 模拟达标 / 能胜任英文工作环境
