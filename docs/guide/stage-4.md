---
title: 阶段 4：突破期（B2 · 10~14 个月 · 累计 900h）
---

*属于[第 3 章 · 阶段详解](/guide/roadmap) · 上一阶段：[阶段 3 · 成长期](/guide/stage-3) · 下一阶段：[阶段 5 · 精进期](/guide/stage-5)*

**阶段定位**：用真实母语材料替代教材，输出量翻倍，引入系统性纠错。**这是决定"哑巴英语"命运的阶段。** 时间配比：显性 10%，精读精听 30%，泛读泛听 35%，输出 25%。

| 模块     | 具体安排                                                                                                                                                     |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **词汇** | 累计 4,500~5,000 词（≈牛津 5000 完成；达到小说/报刊 95% 覆盖）。工具：Anki「COCA 5000/20000」卡组（英文释义，摆脱脑内翻译）+ 句子挖矿 + **启动词根学习**（每周 1~2 个词根族，方法与书单见[4.4](/guide/vocabulary)） |
| **语法** | 序列：过去完成时 → 第三/混合虚拟 → 间接引语 → 被动语态 → 推测情态动词（must be/can't be/might be）→ 冠词精讲（the/零冠词——中国学习者的永恒之痛）→ 动名词/不定式高级搭配。工具：蓝宝书收尾 + 《Advanced Grammar in Use（绿宝书）》选学 |
| **听力** | 进入**看剧学英语**：老友记/摩登家庭为首选（生活语料密度高），配双语字幕工具精看（大陆方案见[第 7 章](/guide/china)），每集两遍：第一遍盲听抓大意，第二遍带字幕精看+挖矿。每周 3~4 集。播客升级：Luke's English Podcast（英音）/The Listening Time             |
| **阅读** | **第一本原版书**：从青少年小说（YA）起步——推荐 *Charlotte's Web*、*Wonder*、*Harry Potter 1*（前 100 页最难，撑过去就顺了）。之后每月 1 本原版。外刊：BBC News / News in Levels 高档位每周 2~3 篇            |
| **口语** | 真人课升到每周 2~3 节（italki 职业教师或 Cambly 随叫随到）；AI 对话保持每周 3 次；开始**复述训练**：看完一集剧/读完一章书，用英语自言自语复述 2 分钟（录音）                                                          |
| **写作** | 每周 200 词短文（书评/剧评/观点文），**必经批改**：AI 精批 + 每 2 周一次真人批改。这一步是防石化的核心——未纠错的输出会永久固化错误                                                                             |

**每周模板（约 15h）**：Anki 7×30min ＋ 语法 2×30min ＋ 精看剧 3 集 ＋ 泛听播客 7×40min ＋ 原版书 5×40min ＋ 真人课 2 节 ＋ AI 口语 3×15min ＋ 复述 3×5min ＋ 写作 1×30min

**毕业标准**：

- [ ] 累计 4,500+ 词
- [ ] 生肉美剧带字幕理解 ≥95%，无字幕 ≥70%
- [ ] Luke's English Podcast 无文稿听懂 ≥80%
- [ ] 原版小说阅读速度 ≥30 页/小时
- [ ] 与外教就抽象话题（社会/职场/观点）讨论 30 分钟不冷场
- [ ] 200 词作文经 AI 批改后错误率逐月下降（可对比存档）
- [ ] （可选验证）雅思 6~6.5 / 剑桥 B2 First 模拟达标
