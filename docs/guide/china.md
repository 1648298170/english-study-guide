## 7.1 完全无墙闭环（零基础 → B2 足够）

```
词汇:  Anki + 不背单词/墨墨
听力:  每日英语听力（聚合 VOA/BBC/新概念/经济学人）+ 可可英语
      + B 站英语区（英语兔=零基础第一站；老友记跟读素材）
教材:  新概念 + 剑桥语法在用三件套 + 书虫（外研社双语版，便宜好买）
口语:  可栗口语/流利说(AI) + HelloTalk(语伴) + italki/Cambly/51Talk(真人)
发音:  ELSA Speak + B 站镜像的 Rachel's English
```

## 7.2 需翻墙（值得但非必需）

- YouTube（沉浸频道、Rachel's English 原版）、Netflix + Language Reactor（双语字幕看剧神器）、ChatGPT 语音、The Daily
- **替代策略**：B 站大量优质镜像与讲解；VOA/BBC 已由每日英语听力合规分发；ChatGPT 语音用国内 AI 口语 App 平替（体验有差距但可用）
