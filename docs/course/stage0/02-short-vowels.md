> 预计学习时间：3~4 小时 · 前置课程：[第 1 课 · 字母与发音入门](./01-alphabet.md) · 每个例词请用词典点读跟读

## 热身：什么是元音，什么是"短"

**元音**：气流从肺里出来，一路畅通、不受到舌头或嘴唇阻挡发出的音，是每个音节的"心脏"。**辅音**则是气流受到各种阻挡发出的音（第 5、6 课）。

**短元音**：发音短促、肌肉松弛的元音。英语里 7 个短元音是高频主角：绝大多数"辅音+元音+辅音"结构的短词（cat、dog、sit）里，元音发的都是短音。

先交代两个记号问题，看美音词典时不会懵：

- 本课的 /e/（bed 里的音），美音词典常标成 /ɛ/，是同一个音
- 本课的 /ɒ/（dog 里的音），美音实际读得更像"短促版的 /ɑː/"，国内教材按 48 音素口径统一写作 /ɒ/

下面 7 个音，一个一个过。每个音都有"发音要领、中文近似音警示、常见拼写、示例单词、最小对比对"五件套。**最小对比对**指只有一个音不同、意思完全不同的词对（如 bad/bed），是练耳朵和嘴巴最快的方法。

## /ɪ/：松弛短促的"衣"

**发音要领**：嘴角微微向两边拉开就够了，不要用力咧嘴；舌头放松，中前部略抬；声音短促，全程不使劲。先拖长读一个 /iː/（"衣"），然后突然"泄劲"，嘴型不变、声音短一截，就是 /ɪ/。

**中文近似音警示**：它像拼音 i 的"没睡醒版"。拼音 i 又紧又亮又长（其实更接近英语的 /iː/），而 /ɪ/ 又松又短又暗。中国学习者的问题不是发不出它，而是**把所有 i 都读成 /iː/**，于是 ship（船）变成 sheep（绵羊）。

**常见拼写**：i（sit、big）；少数词用 y（gym /dʒɪm/ 健身房）。

**示例单词**：

| 单词 | 音标 | 中文 |
|---|---|---|
| sit | /sɪt/ | 坐 |
| big | /bɪɡ/ | 大的 |
| ship | /ʃɪp/ | 船 |
| fish | /fɪʃ/ | 鱼 |
| six | /sɪks/ | 六 |
| this | /ðɪs/ | 这 |
| with | /wɪð/ | 和…一起 |
| win | /wɪn/ | 赢 |

**最小对比对**：ship /ʃɪp/ 船 vs sheep /ʃiːp/ 绵羊（长音 /iː/ 下节课，先感受：一短一长，意思完全不同）；sit /sɪt/ 坐 vs seat /siːt/ 座位。

## /e/：介于"诶"和"哎"之间

**发音要领**：嘴半开，舌尖轻抵下齿，舌前部略抬；嘴形比 /ɪ/ 开、比 /æ/ 闭；声音短促，嘴从头到尾不动。

**中文近似音警示**：最大的坑是读成拼音 ei（"诶"）。/e/ 是纯单元音，**不滑动、嘴不动**；而"诶"有从 /ə/ 滑向 /i/ 的过程。另一个坑：嘴张不够开，把它读成和 /æ/ 不分的音。记住：bed（床）和 bad（坏的）是两个词。

**常见拼写**：e（bed、ten）；特殊：ea 在少数高频词里也发 /e/（bread /bred/ 面包、head /hed/ 头）。

**示例单词**：

| 单词 | 音标 | 中文 |
|---|---|---|
| bed | /bed/ | 床 |
| pen | /pen/ | 钢笔 |
| red | /red/ | 红色的 |
| ten | /ten/ | 十 |
| egg | /eɡ/ | 鸡蛋 |
| leg | /leɡ/ | 腿 |
| best | /best/ | 最好的 |
| when | /wen/ | 什么时候 |

**最小对比对**：bed /bed/ 床 vs bad /bæd/ 坏的；men /men/ 男人们 vs man /mæn/ 男人。

## /æ/：嘴张到最大的短 a

**发音要领**：嘴使劲张大，上下门齿之间能竖着放进两根手指；舌尖抵下齿，舌身放低放平；嘴角向两侧略咧；短促有力。可以对着镜子检查：看不到两指宽的开口，就没到位。

**中文近似音警示**：中文里**没有**这个音，所以必须专门练。"哎"不对（那是 /aɪ/，带滑动）、"啊"也不对（那是 /ɑː/，舌位靠后）。诀窍：嘴张到最大、像医生让你喊"啊"前的张口度，但发一个**不滑动**的短"哎"起点。中国人最常见的错误是嘴偷懒只张一半，把它读成 /e/：bad（坏的）变 bed（床）、man（男人）变 men（男人们）。**这个音是本课的重中之重**。

**常见拼写**：a（cat、hat、black）。

**示例单词**：

| 单词 | 音标 | 中文 |
|---|---|---|
| cat | /kæt/ | 猫 |
| hat | /hæt/ | 帽子 |
| bad | /bæd/ | 坏的 |
| man | /mæn/ | 男人 |
| map | /mæp/ | 地图 |
| apple | /ˈæpl/ | 苹果 |
| hand | /hænd/ | 手 |
| black | /blæk/ | 黑色的 |

**最小对比对**：bad /bæd/ 坏的 vs bed /bed/ 床；pen /pen/ 钢笔 vs pan /pæn/ 平底锅。

## /ɒ/：短促大口的"奥"

**发音要领**：下巴向下打开，嘴比 /æ/ 略收一点；舌头放低、位于口腔中后部；**嘴唇完全放松，不圆唇**；短促。

**中文近似音警示**：拼音 o 是圆唇的（像"哦"的口型），这个音**嘴唇不动**，嘴是上下张开的。另外按上文说明：美音里它读得更开、更接近短促的 /ɑː/。你只要记住三点：短、嘴大开、嘴唇不撅。

**常见拼写**：o（dog、hot）；特殊：w 后面的 a 也常发这个音（want、wash、was）。

**示例单词**：

| 单词 | 音标 | 中文 |
|---|---|---|
| dog | /dɒɡ/ | 狗 |
| hot | /hɒt/ | 热的 |
| box | /bɒks/ | 盒子 |
| stop | /stɒp/ | 停 |
| top | /tɒp/ | 顶部 |
| job | /dʒɒb/ | 工作 |
| want | /wɒnt/ | 想要 |
| on | /ɒn/ | 在…上面 |

**最小对比对**：not /nɒt/ 不 vs nut /nʌt/ 坚果；hot /hɒt/ 热的 vs hut /hʌt/ 小屋。

## /ʊ/：微微圆唇的"乌"的松弛版

**发音要领**：舌后部抬起，嘴唇**只微微拢圆**，像要轻轻吹口气；肌肉放松，声音短促。

**中文近似音警示**：不是"乌"！"乌"嘴唇撮得很紧很突出（那更像英语 /uː/，第 3 课）。/ʊ/ 的嘴唇只圆一点点、力气省一半。最典型的中式错误：把 good 读成"古德"、book 读成"布克"。从今天起，good 是 /ɡʊd/，不是"古德"。

**常见拼写**：oo（book、look）；u（put、full）；ou 在 could、would 里。

**示例单词**：

| 单词 | 音标 | 中文 |
|---|---|---|
| book | /bʊk/ | 书 |
| look | /lʊk/ | 看 |
| good | /ɡʊd/ | 好的 |
| put | /pʊt/ | 放 |
| foot | /fʊt/ | 脚 |
| cook | /kʊk/ | 做饭 |
| wood | /wʊd/ | 木头 |
| full | /fʊl/ | 满的 |

**最小对比对**：full /fʊl/ 满的 vs fool /fuːl/ 傻瓜（/uː/ 第 3 课）；look /lʊk/ 看 vs luck /lʌk/ 运气。

## /ʌ/：含糊短促的"阿"

**发音要领**：嘴自然半开，嘴唇不圆不咧；舌位中低，整个口腔完全不用力；短促、含糊，像轻轻哼一个"啊"但只张开一半嘴。

**中文近似音警示**：别读成"阿"！bus /bʌs/ 不是"巴士"的"巴"（那个音太开、太像 /ɑː/）。也别读成 /e/。它就是"用最少的力气发出来的短 a"。顺带纠一个大坑：love /lʌv/（爱）的拼写是 o 但发音是 /ʌ/，读"辣夫"的同学请自觉重学。

**常见拼写**：u（bus、cup）；o 在 love、mother、come 里；ou 在 young 里。

**示例单词**：

| 单词 | 音标 | 中文 |
|---|---|---|
| cup | /kʌp/ | 杯子 |
| bus | /bʌs/ | 公共汽车 |
| sun | /sʌn/ | 太阳 |
| but | /bʌt/ | 但是 |
| love | /lʌv/ | 爱 |
| mother | /ˈmʌðər/ | 妈妈 |
| up | /ʌp/ | 向上 |
| much | /mʌtʃ/ | 很多 |

**最小对比对**：cap /kæp/ 帽子 vs cup /kʌp/ 杯子；luck /lʌk/ 运气 vs look /lʊk/ 看。

## /ə/：英语里最懒的音（schwa）

**发音要领**：嘴微张，舌头平放在口腔中间，一切肌肉归零，发出一个含糊短促的"呃"。它**只出现在不使劲的音节**（术语叫"非重读音节"，意思是那个音节被轻轻带过）。banana 的 ba 和 na 都不使劲，所以两个 a 都发 /ə/，只有中间的 na 用力发 /næn/。

**中文近似音警示**：中文每个字都咬字清晰，没有"吞音"文化，所以中国人读 about /əˈbaʊt/ 常变成字正腔圆的"阿-宝-特"。而母语者嘴里出现频率最高的元音恰恰是 /ə/：说得越自然，/ə/ 越多。**不会发 /ə/，口语就永远"太用力"、不像英语**。

**常见拼写**：任何元音字母弱读时都可能变成 /ə/：about 的 a、sofa 的 a、computer 的 o、pencil 的 i、today 的 o。（teacher 这类 er 结尾的词，e 也发 /ə/，美音里还带一点卷舌，第 6 课细讲。）

**示例单词**：

| 单词 | 音标 | 中文 |
|---|---|---|
| about | /əˈbaʊt/ | 关于 |
| banana | /bəˈnænə/ | 香蕉 |
| sofa | /ˈsoʊfə/ | 沙发 |
| above | /əˈbʌv/ | 在…上面 |
| computer | /kəmˈpjuːtər/ | 电脑 |
| seven | /ˈsevn/ | 七 |
| today | /təˈdeɪ/ | 今天 |
| pencil | /ˈpensl/ | 铅笔 |

**练习方式**：/ə/ 没有最小对比对（它靠"省力"存在，不靠音色独特），专门的练法是：点读 banana，感受两头轻、中间重，第一和第三个音节的 a 都是含糊的"呃"。以后每学一个多音节词，都问自己：哪个音节最用力？其他音节的元音多半是 /ə/。

## 练习

### 练习一：标出短元音（共 12 题）

写出下列单词中加粗元音对应的短元音音标：

1. s**i**t　2. b**e**d　3. c**a**t　4. d**o**g　5. b**oo**k　6. c**u**p　7. b**a**nana（第一个 a）　8. t**e**n　9. sh**i**p　10. l**oo**k　11. l**u**ck　12. teach**e**r（词尾 er）

<details><summary>点击查看答案</summary>

1. /ɪ/　2. /e/　3. /æ/　4. /ɒ/　5. /ʊ/　6. /ʌ/　7. /ə/　8. /e/　9. /ɪ/　10. /ʊ/　11. /ʌ/　12. /ə/（美音里带一点卷舌，读 /ər/）

全对说明短元音已入门。错得最多的通常是 /æ/ 和 /e/ 混、/ʌ/ 和 /ɒ/ 混，回到对应小节重读。

</details>

### 练习二：最小对比对（共 10 题）

给每组两个词分别注音标（只写元音即可），并用词典点读验证自己读得出来：

1. bed / bad　2. men / man　3. cap / cup　4. not / nut　5. look / luck　6. sit / set　7. pen / pan　8. duck / dark　9. full / fool　10. ship / sheep

<details><summary>点击查看答案</summary>

| 词对 | 元音 | 中文 |
|---|---|---|
| bed / bad | /e/ /æ/ | 床 / 坏的 |
| men / man | /e/ /æ/ | 男人们 / 男人 |
| cap / cup | /æ/ /ʌ/ | 帽子 / 杯子 |
| not / nut | /ɒ/ /ʌ/ | 不 / 坚果 |
| look / luck | /ʊ/ /ʌ/ | 看 / 运气 |
| sit / set | /ɪ/ /e/ | 坐 / 放 |
| pen / pan | /e/ /æ/ | 钢笔 / 平底锅 |
| duck / dark | /ʌ/ /ɑːr/ | 鸭子 / 黑暗的 |
| full / fool | /ʊ/ /uː/ | 满的 / 傻瓜 |
| ship / sheep | /ɪ/ /iː/ | 船 / 绵羊 |

第 8、9、10 组用到了长元音 /ɑː/ /uː/ /iː/，正是下一课的内容：短音嘴一松就完事，长音必须拖够长。

</details>

### 练习三：圈出不同的音（共 6 题）

每组三个词，圈出元音和其他两个不同的那个：

1. cup、bus、sun、put
2. bed、egg、ten、bad
3. box、dog、stop、book
4. ship、sit、big、ten
5. man、map、apple、much
6. love、cup、luck、dog

<details><summary>点击查看答案</summary>

1. put /pʊt/（/ʊ/，其余是 /ʌ/）
2. bad /bæd/（/æ/，其余是 /e/）
3. book /bʊk/（/ʊ/，其余是 /ɒ/）
4. ten /ten/（/e/，其余是 /ɪ/）
5. much /mʌtʃ/（/ʌ/，其余是 /æ/）
6. dog /dɒɡ/（/ɒ/，其余是 /ʌ/，注意 love 的拼写是 o 但发音是 /ʌ/）

</details>

## 本课小结

- 7 个短元音：/ɪ/ /e/ /æ/ /ɒ/ /ʊ/ /ʌ/ /ə/，共同点是短促、松弛
- 中国人三大高危音：/æ/（嘴要张大）、/ʌ/（别读"阿"）、/ə/（学会偷懒）
- good 不是"古德"、love 不是"辣夫"：从短元音开始告别谐音记词
- 最小对比对是最快的练耳方法，bed/bad、ship/sheep 这种差别从此要认真对待
