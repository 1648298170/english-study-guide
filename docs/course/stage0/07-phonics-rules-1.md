> 预计学习时间：3~4 小时 · 前置课程：[第 6 课 · 破擦音、鼻音与其他辅音](./06-consonants-rest.md)（48 音素已集齐，现在开始学"拼"）

## 热身：自然拼读是什么

48 个音素你都会了，但单词是字母拼的，不是音标拼的。**自然拼读（Phonics）就是"字母（组合）到发音"的对应规则**：看到 cat 知道是 /kæt/，听到 /kæt/ 能写出 cat。相当于英语版的拼音表。

先说清楚一个大前提：英语拼写是从几种语言里"拼凑"来的，所以规则大约覆盖七八成常用词，剩下的是例外。**规则是拐杖，不是法律**：见生词先按规则拼，拿不准就查词典听真音。这一课和下一课给你主力规则。

## 一、字母名与字母音：一句话回顾

第 1 课的老朋友，考你一遍：字母 A 的名字叫 /eɪ/，但它在 apple 里发 /æ/、在 cake 里发 /eɪ/。**拼单词永远用字母音，报字母表才用字母名**。

辅音大多老实（b /b/、d /d/、m /m/……），三个两面派要记牢：**c 在 e/i/y 前发 /s/（city），其余多发 /k/（cat）；g 在 e/i/y 前发 /dʒ/（gym），其余多发 /ɡ/（go）；y 在词首发 /j/（yes），在词尾当元音用（my /maɪ/、happy /ˈhæpi/）**。

## 二、CVC 拼读法：见词能读的第一步

**CVC = 辅音 + 元音 + 辅音**，英语里最基础、最大量的词形。三步拼读法，以 cat 为例：

1. 拆音：c = /k/，a = /æ/，t = /t/
2. 慢连：/k/…/æ/…/t/
3. 加速成词：/kæt/，cat！

照这个流程，自己把下面 14 个词各拼三遍（先遮住音标列，拼完对答案）：

| 单词 | 拆音 | 整词 | 中文 |
|---|---|---|---|
| cat | /k/+/æ/+/t/ | /kæt/ | 猫 |
| hat | /h/+/æ/+/t/ | /hæt/ | 帽子 |
| mat | /m/+/æ/+/t/ | /mæt/ | 垫子 |
| bag | /b/+/æ/+/ɡ/ | /bæɡ/ | 包 |
| sad | /s/+/æ/+/d/ | /sæd/ | 难过的 |
| dog | /d/+/ɒ/+/ɡ/ | /dɒɡ/ | 狗 |
| log | /l/+/ɒ/+/ɡ/ | /lɒɡ/ | 原木 |
| hot | /h/+/ɒ/+/t/ | /hɒt/ | 热的 |
| pen | /p/+/e/+/n/ | /pen/ | 钢笔 |
| sit | /s/+/ɪ/+/t/ | /sɪt/ | 坐 |
| big | /b/+/ɪ/+/ɡ/ | /bɪɡ/ | 大的 |
| run | /r/+/ʌ/+/n/ | /rʌn/ | 跑 |
| cup | /k/+/ʌ/+/p/ | /kʌp/ | 杯子 |
| mud | /m/+/ʌ/+/d/ | /mʌd/ | 泥 |

发现规律了吗：**CVC 结构里，元音字母一律发短音**。为什么？看下一节。

## 三、闭音节与开音节：短音还是长音，一眼看穿

先解释术语。**音节**：以一个元音为核心的发音单元，说一个音节嘴巴就"心跳"一次。cat 一拍，是单音节；paper 两拍（pa-per），是双音节（双音节下一课讲）。

**闭音节（元音被关门）**：元音字母后面跟着辅音，像被辅音"关了门"，元音出不去，只好发**短音**。cat、sit、dog、pen 全是闭音节，这就是 CVC 发短音的原因。

**开音节（元音在门口）**：元音字母就在音节末尾，没人关门，元音一路畅通发**长音**，也就是字母名。两类典型：

- 元音直接收尾：go /ɡoʊ/、he /hiː/、no /noʊ/、my /maɪ/、hi /haɪ/
- **魔法 e**（也叫"开音节 e"结构）：`元音 + 辅音 + e`，词尾的 e **自己不发音**，作用是隔着辅音把前面的元音"顶开"，让它发长音。像哑巴守门员，不出声但改变局势

| 短音（闭音节） | 长音（魔法 e） | 变化 |
|---|---|---|
| hat /hæt/ 帽子 | hate /heɪt/ 讨厌 | a: /æ/ → /eɪ/ |
| cap /kæp/ 帽子 | cape /keɪp/ 披风 | a: /æ/ → /eɪ/ |
| kit /kɪt/ 工具箱 | kite /kaɪt/ 风筝 | i: /ɪ/ → /aɪ/ |
| pin /pɪn/ 大头针 | pine /paɪn/ 松树 | i: /ɪ/ → /aɪ/ |
| hop /hɒp/ 单脚跳 | hope /hoʊp/ 希望 | o: /ɒ/ → /oʊ/ |
| not /nɒt/ 不 | note /noʊt/ 笔记 | o: /ɒ/ → /oʊ/ |
| bit /bɪt/ 一点 | bite /baɪt/ 咬 | i: /ɪ/ → /aɪ/ |
| tap /tæp/ 轻敲 | tape /teɪp/ 磁带 | a: /æ/ → /eɪ/ |
| cub /kʌb/ 幼兽 | cube /kjuːb/ 立方体 | u: /ʌ/ → /juː/ |
| tub /tʌb/ 浴缸 | tube /tuːb/ 管子 | u: /ʌ/ → /uː/ |

（u 的长音有两种：/juː/ 更常见如 cube、cute；个别词读 /uː/ 如 tube、rule。）

一封写给 e 的感谢信：一个不发音的字母，凭一己之力区分了 hat（帽子）和 hate（讨厌）、hop（跳）和 hope（希望）。**看到词尾 e，先问它是不是魔法 e，别急着忽略它。**

## 四、常见字母组合：一次记一串

两个字母联手发一个固定音，把它们当"一张牌"记，不要拆开拼：

| 组合 | 发音 | 例词 | 中文 |
|---|---|---|---|
| ch | /tʃ/ | chair、teacher、lunch、child | 椅子、老师、午饭、孩子 |
| sh | /ʃ/ | ship、fish、wash、she | 船、鱼、洗、她 |
| th（清） | /θ/ | three、think、thank、mouth | 三、想、感谢、嘴 |
| th（浊） | /ð/ | this、that、mother、they | 这、那、妈妈、他们 |
| ph | /f/ | phone、photo、elephant | 电话、照片、大象 |
| wh | /w/ | what、white、why | 什么、白色的、为什么 |
| ck | /k/ | duck、black、sick、clock | 鸭子、黑色的、生病的、钟 |
| ng | /ŋ/ | sing、king、long、song | 唱歌、国王、长的、歌 |

三点评注：

1. **th 的清浊分工**（第 5 课讲过）：实词多为清音 /θ/（three、mouth），虚词多为浊音 /ð/（this、the、they）。遇到 th 先咬舌尖，再挑清浊
2. **wh 的例外**：who /huː/（谁）里 wh 读 /h/，w 反而不发音。whose 同理。高频词，单独记住
3. **赠送两个静音组合**：kn 的 k 不发音（know /noʊ/、knife /naɪf/ 刀），wr 的 w 不发音（write /raɪt/、wrong /rɔːŋ/ 错的）。第 6 课见过的老朋友

## 本课小结

- CVC 三步拼读：拆音、慢连、加速成词，元音一律发短音
- 闭音节（元音被辅音关门）发短音；开音节（元音收尾或魔法 e）发长音（字母名）
- 魔法 e 不发音，但把 hat 变 hate、hop 变 hope
- 字母组合 ch sh th ph wh ck ng 当"一张牌"整体记；wh 的例外是 who 读 /h/
- kn、wr 是静音组合：know 读 /noʊ/、write 读 /raɪt/
