> 预计学习时间：3~4 小时 · 前置课程：[第 7 课 · 自然拼读规则（上）](./07-phonics-rules-1.md) · 本课学完，你就能自己拼读大部分双音节词

## 热身：本课三大件

1. **元音组合**：两个元音字母手拉手（oo、ee、ea……），读法基本固定
2. **r 控元音**：r 站在元音后面，元音就变了味（car、bird、turn）
3. **音节划分**：把长词切成小段，每段按已学规则读，再连起来

学完这三样，你会突然发现：超市里的英文包装、歌单里的英文歌名，大部分都能自己拼出来了。

## 一、元音组合：两个元音手拉手

先记一条总口诀：**两个元音走一起，多半第一个当发言人**（ai、ee、oa 都是这样）。但有几个组合有两个读音，表格里都标出来了：

| 组合 | 主音 | 例词 | 第二读音 | 例词 |
|---|---|---|---|---|
| oo | /uː/ | moon、food、school、cool | /ʊ/ | book、look、good、foot |
| ee | /iː/ | tree、see、green、week | （没有第二读） | |
| ea | /iː/ | sea、read、eat、teacher | /e/ | bread、head、ready |
| ai | /eɪ/ | rain、wait、train | （没有第二读） | |
| ay | /eɪ/ | day、play、say | （没有第二读） | |
| oa | /oʊ/ | boat、coat、road、goat | （没有第二读） | |
| ow | /oʊ/ | snow、slow、grow、yellow | /aʊ/ | now、cow、down、how |
| ou | /aʊ/ | house、out、about、mouth | /oʊ/（少见） | soul 灵魂 |
| oi | /ɔɪ/ | coin、oil、join | （没有第二读） | |
| oy | /ɔɪ/ | boy、toy、enjoy | （没有第二读） | |

四条记法：

- **ai 与 ay 是同一件衣服**：/eɪ/。ai 多在词中（rain），ay 多在词尾（day）。oi 与 oy 同理：/ɔɪ/，词中 oi、词尾 oy
- **ee 最听话**：永远 /iː/
- **oo 有两副面孔**：长音 /uː/（moon）和短音 /ʊ/（book）。好消息是 book、look、good、foot、cook 这批高频词都是短音，见多了自然记住
- **ow 是双面间谍**：snow 是 /oʊ/、now 是 /aʊ/，遇到 ow 先按高频赌一把，拿不准查词典

## 二、r 控元音：元音被 r 抓走了

r 的威力第 3 课领教过：元音一碰到身后的 r，就不再是普通的长音短音，整个读成"元音 + 卷舌"的合体，术语叫 **r 控元音**（r-controlled vowel）：

| 组合 | 读音 | 例词 | 中文 |
|---|---|---|---|
| ar | /ɑːr/ | car、star、far、park、farm、garden | 汽车、星星、远的、公园、农场、花园 |
| or | /ɔːr/ | for、horse、morning、north、sport | 为了、马、早晨、北方、运动 |
| er | /ɜːr/ | her、sister、person | 她的、姐妹、人 |
| ir | /ɜːr/ | bird、girl、first、shirt | 鸟、女孩、第一、衬衫 |
| ur | /ɜːr/ | turn、nurse、purple、Thursday | 转动、护士、紫色、星期四 |

三条要点：

1. **er、ir、ur 是三胞胎**，全部读 /ɜːr/，拼写随便挑，发音一个样
2. 别把 ar 拆开读成"短 a + r"：car /kɑːr/ 不是"开儿"；也别把 er 组读成 /e/ 或 /ɪ/：bird /bɜːrd/ 的核心就是那个又卷又闷的 /ɜːr/
3. **词尾 er 的特殊待遇**：teacher、sister、doctor 这类词尾 er 在非重读音节里，读得又轻又快，介于 /ər/（美式带卷舌的"呃"）。所以 teacher /ˈtiːtʃər/ 的尾巴又轻又含糊，别读成重重的 /ɜːr/

## 三、音节划分：双辅音分，单辅音归后

双音节词怎么下手？先切开，再逐段拼，最后连读。**音节**就是以元音为核心的发音单元（第 7 课讲过），双音节词里有两个元音核心。切分两条主规则：

**规则一：两个元音之间有两个辅音，一人一个（VCCV）**

happy → hap-py，rabbit → rab-bit，basket → bas-ket，sister → sis-ter，pencil → pen-cil，doctor → doc-tor

切开之后，第一段多半变成闭音节，元音发短音：hap /hæp/、rab /ræb/、pen /pen/。

**规则二：两个元音之间只有一个辅音，归后面（VCV）**

open → o-pen，paper → pa-per，lazy → la-zy，tiger → ti-ger，music → mu-sic，zero → ze-ro

辅音归后之后，第一段变成了开音节（元音收尾），元音发长音（字母名）：o /oʊ/、pa /peɪ/、la /leɪ/、ti /taɪ/。这就是第 7 课开音节规则在双音节词里的应用，一条规则吃两遍。

**重音小知识**：词典里音标前的上标 /ˈ/ 表示重读音节（更响更长的那个），双音节名词和形容词的重音绝大多数在第一音节（/ˈhæpi/、/ˈpeɪpər/）。读词时让第一个音节"重"一点，听起来立刻地道很多。

警告（重要）：音节规则和拼写规则一样，**是统计规律不是铁律**。seven /ˈsevn/ 两个元音间单辅音 v 却切在前面（sev-en 闭音节短音）、pencil 的 cil 读 /sl/ 不规则……遇到"按规则读出来很怪"的词，一律以词典发音为准。

## 四、双音节词拼读实战：17 个词打通任督二脉

流程示范：**basket** → bas-ket → bas（闭音节 /bæs/）+ ket（闭音节 /kɪt/）→ 连读 /ˈbæskɪt/，篮子。自己先把 17 个词全部切分拼读一遍，再对答案：

| 单词 | 切分 | 读音 | 中文 |
|---|---|---|---|
| happy | hap-py | /ˈhæpi/ | 开心的 |
| rabbit | rab-bit | /ˈræbɪt/ | 兔子 |
| basket | bas-ket | /ˈbæskɪt/ | 篮子 |
| pencil | pen-cil | /ˈpensl/ | 铅笔 |
| sister | sis-ter | /ˈsɪstər/ | 姐妹 |
| doctor | doc-tor | /ˈdɑːktər/ | 医生 |
| kitten | kit-ten | /ˈkɪtn/ | 小猫 |
| paper | pa-per | /ˈpeɪpər/ | 纸 |
| open | o-pen | /ˈoʊpən/ | 打开 |
| lazy | la-zy | /ˈleɪzi/ | 懒的 |
| tiger | ti-ger | /ˈtaɪɡər/ | 老虎 |
| music | mu-sic | /ˈmjuːzɪk/ | 音乐 |
| zero | ze-ro | /ˈzɪroʊ/ | 零 |
| morning | mor-ning | /ˈmɔːrnɪŋ/ | 早晨 |
| water | wa-ter | /ˈwɔːtər/ | 水 |
| yellow | yel-low | /ˈjeloʊ/ | 黄色的 |
| window | win-dow | /ˈwɪndoʊ/ | 窗户 |

品味一下：paper 的 pa 发长音（单辅音归后）、happy 的 hap 发短音（双辅音分开），morning 里 or 是 /ɔːr/、water 的词尾 er 轻读。前两课的所有规则在这 17 个词里全用上了。

## 五、规则是拐杖，不是法律（必读）

英语的拼写是从盎格鲁、法国人、拉丁语那儿层层叠叠借来的，所以**任何拼读规则都有例外**。下面这批高频例外词，长着规则的脸，读着规则的反对派：

| 单词 | 按规则会读成 | 实际读音 | 中文 |
|---|---|---|---|
| have | /heɪv/ | /hæv/ | 有 |
| come | /koʊm/ | /kʌm/ | 来 |
| some | /soʊm/ | /sʌm/ | 一些 |
| give | /ɡaɪv/ | /ɡɪv/ | 给 |
| one | /oʊn/ | /wʌn/ | 一 |
| two | /twoʊ/ | /tuː/ | 二 |
| said | /seɪd/ | /sed/ | 说（过去式） |
| bread | /briːd/ | /bred/ | 面包 |
| friend | /friːnd/ | /frend/ | 朋友 |
| who | /woʊ/ | /huː/ | 谁 |

这类"魔法 e 不生效"的词（have、come、give、love）和古老拼写词（one、two、who）数量有限，全是超高频词，当熟脸整体记即可，不必总结规律。

**正确的三步工作流**：见到生词 → 按规则拼出声 → 词典点读验证。一致，皆大欢喜；不一致，以词典为准，把这个词记成特例。日积月累，你脑中会同时长出"规则引擎"和"例外词库"，这正是母语者的工作方式。

3. pa-per /ˈpeɪpər/ 纸

### 练习四：高频例外词认脸（共 6 题）

写出下列单词的实际读音（都在第五节出现过）：

have、one、two、said、bread、friend

<details><summary>点击查看答案</summary>

1. have /hæv/ 有（魔法 e 不生效）
2. one /wʌn/ 一（o 读 /wʌ/，纯例外）
3. two /tuː/ 二（w 不发音）
4. said /sed/ 说（ai 读 /e/）
5. bread /bred/ 面包（ea 读 /e/）
6. friend /frend/ 朋友（ie 读 /e/）

这些词每个都出现几百次，值得单独做成小卡片，读音和拼写"打包硬记"。

</details>

## 本课小结

- 元音组合两两牵手：ee/ai/ay/oa/oi/oy 读音唯一；oo、ea、ow、ou 有两个常见读音
- r 控元音三巨头：ar /ɑːr/、or /ɔːr/、er-ir-ur /ɜːr/；词尾 er 弱读 /ər/
- 音节划分：双辅音一人一个、单辅音归后（归后则前面发长音）
- 双音节词拼读 = 切分 + 逐段拼 + 重音放前 + 连读
- **规则是拐杖不是法律**：按规则读，用词典验，例外词整体记
