title: 第 4 课 · 双元音
---

> 预计学习时间：3~4 小时 · 前置课程：[第 3 课 · 长元音](./03-long-vowels.md) · 例词多带 r，记得卷舌

## 热身：双元音就是"滑动"

**双元音**：两个元音连成一体、从一个滑到另一个，听起来像一个音。要点只有八个字：**前重后轻，一滑到底**。第一个音饱满响亮，第二个音轻轻收尾，中间不许停顿。

中文母语者读双元音的通病恰恰相反：前轻后重、或者干脆只读一半不滑动，于是 name 像拼音 nem、now 像"闹"。这一课的每个音都要练"滑"的感觉：读慢一点，夸张地滑，先难听后好听。

记号说明：本课最后三个音是"元音 + r"的组合。美音写法是 /ɪr/ /er/ /ʊr/（终点卷舌），英式教材写 /ɪə/ /eə/ /ʊə/（终点不卷舌，滑向"呃"）。同理美音 /oʊ/ 对应英式 /əʊ/。你看英音材料时对得上就行，本课程统一用美音写法。

## /eɪ/：诶→衣 的滑动（字母 A 的名）

**发音要领**：从 /e/（bed 的元音）出发，滑向 /ɪ/，下巴微微上抬合拢；前重后轻，一气呵成。这就是字母 A 的字母名 /eɪ/，感受一下你报字母表时有多自然，那个滑动就是标准动作。

**中文近似音警示**：拼音 ei（"诶"）起点偏高、而且嘴基本不动。英语 /eɪ/ 起点是 /e/，嘴要滑。两个典型错误：读成纯 /e/（name 读成 nem），或者滑动过猛读成"爱"（name 读成"奈姆"，那个"奈"起点嘴太开）。

**常见拼写**：a + 辅音 + e（name、cake）；ai（rain）；ay（day）；ey（they 他们）；eigh（eight 八）。

**示例单词**：

| 单词 | 音标 | 中文 |
|---|---|---|
| name | /neɪm/ | 名字 |
| day | /deɪ/ | 天 |
| cake | /keɪk/ | 蛋糕 |
| rain | /reɪn/ | 雨 |
| say | /seɪ/ | 说 |
| play | /pleɪ/ | 玩 |
| eight | /eɪt/ | 八 |
| late | /leɪt/ | 迟到的 |

**最小对比对**：pen /pen/ 钢笔 vs pain /peɪn/ 疼痛；men /men/ 男人们 vs main /meɪn/ 主要的；wet /wet/ 湿的 vs wait /weɪt/ 等待。

## /aɪ/：张大嘴滑到"衣"（字母 I 的名）

**发音要领**：从大张嘴的 /a/ 出发，滑向 /ɪ/，下巴从大开收到半闭；前重后轻。

**中文近似音警示**：拼音 ai（"爱"）是最近的音，但"爱"的动程短、起点舌位靠前。英语 /aɪ/ 起点嘴更开、滑得更足。最常见的错：终点丢失，把 my /maɪ/ 读成"买"、like /laɪk/ 读成"来克"。记住结尾必须碰到 /ɪ/。

**常见拼写**：i + 辅音 + e（time、bike）；y（my、why）；igh（night、high）；i 在开音节（hi 嗨）。

**示例单词**：

| 单词 | 音标 | 中文 |
|---|---|---|
| time | /taɪm/ | 时间 |
| like | /laɪk/ | 喜欢 |
| my | /maɪ/ | 我的 |
| five | /faɪv/ | 五 |
| night | /naɪt/ | 夜晚 |
| why | /waɪ/ | 为什么 |
| high | /haɪ/ | 高的 |
| bike | /baɪk/ | 自行车 |

**最小对比对**：time /taɪm/ 时间 vs tame /teɪm/ 驯服的；mine /maɪn/ 我的 vs mane /meɪn/ 鬃毛。

## /ɔɪ/：圆着嘴滑到"衣"

**发音要领**：从圆唇的 /ɔ/ 出发，滑向 /ɪ/，嘴唇从圆变扁；前重后轻，一口气滑完。

**中文近似音警示**：中文里没有 oi 这个组合，最容易犯的错是把它拆成两个音："哦一"。它是一个音！也别把 boy 读成"抱伊"。诀窍：先摆好 /ɔː/ 的圆嘴（含半个鸡蛋），发声的瞬间立刻往 /ɪ/ 滑。

**常见拼写**：oi（coin、oil）；oy（boy、toy）。规律：oi 多在词中，oy 多在词尾。

**示例单词**：

| 单词 | 音标 | 中文 |
|---|---|---|
| boy | /bɔɪ/ | 男孩 |
| toy | /tɔɪ/ | 玩具 |
| oil | /ɔɪl/ | 油 |
| coin | /kɔɪn/ | 硬币 |
| noise | /nɔɪz/ | 噪音 |
| voice | /vɔɪs/ | 声音 |
| join | /dʒɔɪn/ | 加入 |
| joy | /dʒɔɪ/ | 快乐 |

**最小对比对**：boy /bɔɪ/ 男孩 vs buy /baɪ/ 买；toy /tɔɪ/ 玩具 vs tie /taɪ/ 领带。

## /oʊ/：越滑嘴越圆（字母 O 的名）

**发音要领**：从微微圆唇的 /o/ 出发，滑向 /ʊ/，嘴唇逐渐收圆前突；前重后轻。这就是字母 O 的名字 /oʊ/。

**中文近似音警示**：拼音 ou（"欧"）起点不圆唇、嘴是扁的；英语 /oʊ/ 从头到尾都在圆唇，只是越来越圆。别把 no 读成"nou"、go 读成"勾"。也要和 /ɔː/ 分清：go /ɡoʊ/ 嘴唇滑动，door /dɔːr/ 嘴唇定住不动。（英式教材把这个音写作 /əʊ/，对应关系记住即可。）

**常见拼写**：o + 辅音 + e（home、note）；o 在开音节（go、no）；oa（boat、coat）；ow（snow、slow）；old（old、cold）。

**示例单词**：

| 单词 | 音标 | 中文 |
|---|---|---|
| go | /ɡoʊ/ | 去 |
| home | /hoʊm/ | 家 |
| no | /noʊ/ | 不 |
| boat | /boʊt/ | 小船 |
| know | /noʊ/ | 知道 |
| slow | /sloʊ/ | 慢的 |
| coat | /koʊt/ | 外套 |
| old | /oʊld/ | 老的 |

**最小对比对**：coat /koʊt/ 外套 vs caught /kɔːt/ 抓住；boat /boʊt/ 小船 vs bought /bɔːt/ 买（buy 的过去式）。

## /aʊ/：张大嘴滑到"乌"

**发音要领**：从大张嘴的 /a/ 出发，滑向 /ʊ/，嘴唇从大开收成微圆；前重后轻。

**中文近似音警示**：拼音 ao（"奥"）的终点是扁嘴的，英语 /aʊ/ 的终点嘴唇要收圆。所以 now /naʊ/ 不是"闹"，house /haʊs/ 不是"好斯"。反过来也别读成 /oʊ/：now 和 no 是两个词。

**常见拼写**：ou（house、out）；ow（now、cow）。规律：ow 既可能是 /aʊ/ 也可能是 /oʊ/（snow 是 /oʊ/），见词要查，第 8 课有归纳。

**示例单词**：

| 单词 | 音标 | 中文 |
|---|---|---|
| now | /naʊ/ | 现在 |
| house | /haʊs/ | 房子 |
| cow | /kaʊ/ | 奶牛 |
| down | /daʊn/ | 向下 |
| out | /aʊt/ | 外面 |
| mouth | /maʊθ/ | 嘴 |
| town | /taʊn/ | 城镇 |
| how | /haʊ/ | 怎样 |

**最小对比对**：now /naʊ/ 现在 vs no /noʊ/ 不；how /haʊ/ 怎样 vs hoe /hoʊ/ 锄头。

## /ɪr/：松弛的"衣"+ 卷舌（here 组）

**发音要领**：从 /ɪ/（松弛短促的衣）出发，快速滑向卷舌的 r：舌尖卷起，悬空不碰任何地方；前重后轻。美音的卷舌是灵魂，英式 /ɪə/ 不卷舌、滑向"呃"，听感完全不同。

**中文近似音警示**：两大典型错误：一是**丢卷舌**，here /hɪr/ 读成"嘿"或"嘿啊"，听起来像 he（他）；二是**起点太紧**，读成 /iːr/ 拖长。正确动作：短 /ɪ/ 一步卷到位，干脆利落。

**常见拼写**：ear（hear、ear、year）；eer（beer、deer、cheer）；ere（here）。

**示例单词**：

| 单词 | 音标 | 中文 |
|---|---|---|
| here | /hɪr/ | 这里 |
| hear | /hɪr/ | 听见 |
| ear | /ɪr/ | 耳朵 |
| year | /jɪr/ | 年 |
| near | /nɪr/ | 近的 |
| deer | /dɪr/ | 鹿 |
| cheer | /tʃɪr/ | 欢呼 |
| beer | /bɪr/ | 啤酒 |

**最小对比对**：hear /hɪr/ 听见 vs hair /her/ 头发；beer /bɪr/ 啤酒 vs bear /ber/ 熊。

## /er/：从"bed 的 e"滑向卷舌（hair 组）

**发音要领**：从 /e/（bed 的元音）出发，滑向卷舌的 r；前重后轻。

**中文近似音警示**：最经典的错误是把 hair 读成"海尔"。注意：海尔品牌的英文 Haier 念起来接近英语 her /hɜːr/（她的），而 hair 的起点是 /e/，嘴更开、更扁。起点既不是 /æ/ 也不是 /ɑː/，就是 bed 里那个 /e/，然后卷舌。

**常见拼写**：air（air、hair、chair）；are（care、share）；ear（bear、pear）；ere（there、where）；eir（their）。

**示例单词**：

| 单词 | 音标 | 中文 |
|---|---|---|
| air | /er/ | 空气 |
| hair | /her/ | 头发 |
| care | /ker/ | 关心 |
| pear | /per/ | 梨 |
| where | /wer/ | 哪里 |
| there | /ðer/ | 那里 |
| chair | /tʃer/ | 椅子 |
| bear | /ber/ | 熊 |

**最小对比对**：hair /her/ 头发 vs her /hɜːr/ 她的；chair /tʃer/ 椅子 vs cheer /tʃɪr/ 欢呼。

## /ʊr/：从"book 的 u"滑向卷舌（tour 组）

**发音要领**：从 /ʊ/（book 的元音）出发，滑向卷舌的 r，嘴唇从微圆过渡到卷舌；前重后轻。

**中文近似音警示**：这组词不多，别读成重重的"无尔"。另外要心里有数：英语正在变化中，很多美国人把 sure、poor 读成 /ʃʊr/ 或卷舌更狠的 /ʃɝ/（如 sure 读得接近"舒尔"）两种之一都算对，词典和真人略有出入很正常，别钻牛角尖。（英式写 /ʊə/。）

**常见拼写**：our（tour）；oor（poor）；ure（sure、pure、cure）。

**示例单词**：

| 单词 | 音标 | 中文 |
|---|---|---|
| tour | /tʊr/ | 游览 |
| tourist | /ˈtʊrɪst/ | 游客 |
| poor | /pʊr/ | 贫穷的 |
| sure | /ʃʊr/ | 确信的 |
| pure | /pjʊr/ | 纯的 |
| cure | /kjʊr/ | 治愈 |

**最小对比对**：poor /pʊr/ 贫穷的 vs pour /pɔːr/ 倒、灌；tour /tʊr/ 游览 vs tore /tɔːr/ 撕（tear 的过去式）。

### 练习三：圈出不同的音（共 6 题）

每组三个词，圈出元音和其他两个不同的那个：

1. day、say、rain、pen
2. my、night、five、man
3. boy、toy、joy、now
4. go、boat、know、door
5. house、cow、now、hoe
6. here、near、year、hair

<details><summary>点击查看答案</summary>

1. pen /pen/（/e/，其余是 /eɪ/）
2. man /mæn/（/æ/，其余是 /aɪ/）
3. now /naʊ/（/aʊ/，其余是 /ɔɪ/）
4. door /dɔːr/（/ɔː/，其余是 /oʊ/）
5. hoe /hoʊ/（/oʊ/，其余是 /aʊ/）
6. hair /her/（/er/，其余是 /ɪr/）

</details>

## 本课小结

- 双元音 8 个：/eɪ/ /aɪ/ /ɔɪ/ /oʊ/ /aʊ/ /ɪr/ /er/ /ʊr/，核心动作是"前重后轻，一滑到底"
- 字母 A、I、O 的字母名就是 /eɪ/ /aɪ/ /oʊ/，报字母表就是在练双元音
- 最后三个 /ɪr/ /er/ /ʊr/ 是美音特色：终点必须卷舌，here 不卷舌就变成 he
- 美音和英音记法对应：/oʊ/ 对 /əʊ/，/ɪr/ /er/ /ʊr/ 对 /ɪə/ /eə/ /ʊə/
- 至此 20 个元音全部学完，下一课开始攻克 28 个辅音
