## 英语词汇的三个世界

英语不是一门"纯血"语言。它被征服过、被文艺复兴"补课"过，所以今天的英语词典里其实叠着三层历史：

| 层次 | 什么时候进来 | 长什么样 | 例子 |
|---|---|---|---|
| 第一层：盎格鲁-撒克逊本族语 | 英语诞生之初 | 短、硬、基础，管吃喝住行 | ask, get, take, fire, help, hand |
| 第二层：法语-拉丁层 | 1066 年诺曼征服后，经法语进入 | 音节变多、语体更正式 | question, people, use, judge, very |
| 第三层：拉丁、希腊学术层 | 文艺复兴前后直接从拉丁语、希腊语借入 | 长、书面、结构完整 | interrogate, transport, telephone, biology |

三层历史最直观的展示方式，是拿"问"这一个意思在三层里各取一个词：

- **ask**（本族语）：I **asked** her the way to the station. 随口一问。
- **question**（法语-拉丁层）：The lawyer **questioned** the witness for an hour. 正式、成系统地盘问。
- **interrogate**（拉丁直借，学术层）：The police **interrogated** the suspect all night. 严肃到带压迫感的审问。

三个词都是"问"，但长短、场合、火力完全不同。这就是英语的"同义三层"现象：本族语词口语化，法语层词正式，拉丁直借词最书卷气。

希腊学术层则贡献了大量"拼装词"：**telephone** = tele（远）+ phone（声音），"远处的声音"；**biology** = bio（生命）+ logy（学科），"研究生命的学科"。这一层的词几乎个个都能这样拆。

## 两个世界：为什么前 2000 词拆不动，3000 词以后拆得动

现在回答本课标题里的"两个世界"。对学习者来说，英语词汇其实分成两个可操作的世界：

- **不可拆的世界**：约前 2000 高频词。它们要么是本族语短词（get、take、make），要么是法语层里被几百年口语"磨圆了棱角"的词——比如 very，追祖上是拉丁 verus"真实的"，但你今天再用"真实"去拆它，一点忙都帮不上。这个世界里的词短、熟、高频，整体记忆就是最优解，你在 A1 到 B2 已经干完了这件事。
- **可拆的世界**：3000 词以后的中低频学术词、书面词。它们大量来自第三层，是整根整根从拉丁语、希腊语搬进来的，词根、前缀、后缀还鲜灵灵地摆在表面：transport、inspect、reform、factory……这正是你现在站着的门口。

所以词根战略不早教、也不算晚：B2 毕业正好是你词汇量冲进"可拆区"的起点。接下来 12 课要做的，就是给这个世界装上"偏旁部首"，把死记变成理解记忆。

## 词根、前缀、后缀：一张解剖图

拿 **unpredictable**（不可预测的）上解剖台：

```
un      +      pre      +      dict      +      able
前缀           前缀             词根            后缀
"不"           "提前"           "说"            "能……的"
```

从左往右读：**不可**被**提前**地**说出**的 → 不可预测的。一个四层结构的词，意思就是这么像算式一样叠出来的。

三个部件的分工：

| 部件 | 位置 | 管什么 | 例子 |
|---|---|---|---|
| 词根 | 中间，词的心脏 | 核心意思 | dict = 说 |
| 前缀 | 前面 | 方向、否定、时间、强度 | pre- 提前；un- 不 |
| 后缀 | 后面 | 词性和身份 | -able 形容词后缀 |

给你一个数量感：常用前缀大约几十个，常用后缀大约几十个，复用率极高；常用词根一两百个就能覆盖学术英语的大半。本课程先攻其中最高频的一批。前缀后缀是"一次性投资、终身分红"的部分，词根是主战场。

## 拆词三步法

从这一课起，见到一个可拆区的生词，按固定流程走三步：

1. **找词根**：在词的中段找到"意思心脏"，确定核心义（比如看到 spect，心里亮起一个字：看）。
2. **认前缀**：把首段的前缀翻译成方向或态度（in- 向内、re- 一再/往回、pro- 向前……）。
3. **数后缀**：看尾巴定词性和身份（-ion 名词、-able 形容词、-ator 人……）。

三步走完得到的是一个**有方向的猜测**。最后一步永远是拿词典核对——拆词给你过河的桥，词典才是对岸。

用 spect（看）家族完整走一遍：

| 单词 | 拆解 | 一步一步推 |
|---|---|---|
| inspect | in-(向内) + spect(看) | 往里面看 → 检查 |
| respect | re-(一再) + spect(看) | 反复看、郑重地看 → 尊重 |
| prospect | pro-(向前) + spect(看) | 向前望见的东西 → 前景；可能性 |
| spectator | spect(看) + -ator(……的人) | 看的人 → 观众 |
| perspective | per-(透过) + spect(看) + -ive | 透过它看出去的那个位置 → 视角 |
| suspect | sus-(从下面) + spect(看) | 从下面偷偷打量 → 怀疑 |

注意到了吗：词根没变，只换前缀，六个词就排成了一串糖葫芦。这就是词根法的威力——记住一个 spect，等于给六个词各装了一个挂钩。

## 试拆十个词

下面十个词都是你大概率见过或即将高频见到的词。先别看答案，用三步法逐个拆，把结构和猜测写在本子上，再对答案。拆错了也值得——错的地方就是你和自己词根库的对账单。

1. predict
2. export
3. transport
4. inspect
5. reform
6. factory
7. vision
8. audio
9. subway
10. telephone

<details>
<summary>点击查看答案</summary>

1. predict = pre-(提前) + dict(说) → 提前说出 → **预测**。解析：dict"说"是你第 2 课要正式学的词根。
2. export = ex-(向外) + port(运) → 运出去 → **出口**。解析：port"运、携带"，第 3 课主角之一。
3. transport = trans-(跨越) + port(运) → 跨越着搬运 → **运输**。解析：trans- 的画面感强：从此岸到彼岸。
4. inspect = in-(向内) + spect(看) → 往里看 → **检查**。解析：上表刚拆过，检验一下瞬时记忆。
5. reform = re-(重新) + form(形) → 重新塑形 → **改革**。解析：form"形"，第 4 课见。
6. factory = fact(做) + -ory(地方) → 做东西的地方 → **工厂**。解析：fact"做"，factory 不是"事实的仓库"。
7. vision = vis(看) + -ion(名词后缀) → 看的能力；看见的景象 → **视力；愿景**。解析：vis 与 vid 是"看"的两种拼写，第 5 课见。
8. audio = aud(听) → 与听有关的 → **音频**。解析：aud"听"，第 5 课见。
9. subway = sub-(下面) + way(路) → 地下的路 → **地铁**。解析：注意 way 是本族语词，这说明前缀也能焊在本族语成分上，不是所有可拆词都是纯拉丁货。
10. telephone = tele(希腊语：远) + phone(希腊语：声音) → 远处的声音 → **电话**。解析：两个希腊词根，一个前缀都没有——词根也可以直接堆叠。

</details>

十个里猜对方向七个以上，说明你的"词感"已经就位；不足七个也没关系，这正是这门课要练的能力，后面每一课都有大量机会。

## 中文母语者常见误区

| ❌ 误区 | ✅ 正确姿势 | 为什么 |
|---|---|---|
| 见到长单词就想拆，以为所有英语词都有词根 | 先判断词源层：take、get、help 这类本族语短词没有拉丁词根可拆 | 词根法只对拉丁、希腊层有效；对第一层词强行拆解只会拆出噪音 |
| 以为词根义相加永远等于词义，比如把 novel 硬推成"新的"就懵了它为什么是"小说" | 拆解给出"方向感"后，精确词义必须回词典核对 | novel 确实含词根 nov(新)（本义"新奇的故事"，后专指小说体）；从"新"到"小说"隔着几百年的词义引申，拆词是理解工具，不替词典做主 |
| 用词根自己造词：想说"说不出来"就拼一个 *redict* | 表达"无法预料的"用词典里真实存在的 unpredictable | 词根是解码工具，不是造词积木；说和写只用查得到的词 |
| 觉得学了词根就不用记单词了 | 词根降低记忆成本，但每个词的拼写、搭配、读音仍要单独巩固 | 词根给你挂钩，把词挂上钩、挂牢，还得靠复习和使用 |

## 练习答案

<details>
<summary>点击查看答案</summary>

**一、判断词源层**

1. help → 本族语层
2. telephone → 拉丁、希腊学术层（tele 远 + phone 声音）
3. question → 法语-拉丁层
4. biology → 拉丁、希腊学术层（bio 生命 + logy 学科）
5. transport → 拉丁、希腊学术层（trans- 跨越 + port 运）

**二、拆词分析**

1. preview = pre-(提前) + view(看) → 提前看 → 预览。解析：view 与 vis 同出拉丁"看"，是它经法语磨圆了的兄弟。
2. revisit = re-(再) + visit(去看) → 再去看 → 重访；重温。解析：visit 本身含 vis(看)。
3. imperfect = im-(不) + per-(彻底) + fect(做) → 做得不彻底的 → 不完美的。解析：im- 是 in- 在字母 p 前的变形。
4. transportation = trans-(跨越) + port(运) + -ation(名词后缀) → 跨越式搬运 → 运输；交通工具。解析：后缀 -ation 只改词性，不改核心义。

**三、指出成分**

1. unpredictable：前缀 un-(不) + 前缀 pre-(提前) + 词根 dict(说) + 后缀 -able(能……的) → 不可预测的。一个词可以叠两个前缀。
2. exporter：前缀 ex-(向外) + 词根 port(运) + 后缀 -er(……的人) → 出口商。
3. inspector：前缀 in-(向内) + 词根 spect(看) + 后缀 -or(……的人) → 检查员。解析：-or 和 -er 干同样的活。

**四、选词填空**

1. inspected（往里看 → 检查）
2. respect（反复看重地看 → 尊重）
3. prospects（向前看到的东西 → 前景，常用复数）
4. spectators（看的人 → 观众）
5. perspective（透过它看出去的位置 → 视角）

**五、中译英**

1. No one can predict the future.
2. The customs officer inspected my luggage.
3. From my perspective, this problem is easy to solve.

</details>
