## 本课目标

so 和 such 都表示"如此、这么"，意思几乎一样，词性却不同——一个是副词，一个是形容词路数的限定词。就这一点点差别，衍生出考试里最经典的词序题。学完这一课，你应该能做到：

- [ ] 一眼判断"这么漂亮的一个女孩"是 so beautiful a girl 还是 such a beautiful girl（其实两个都对，词序不同！）
- [ ] 记住 so many / so much / so few / so little 只能配 so，不能配 such
- [ ] 用 so...that 和 such...that 写出"如此……以至于"的句子
- [ ] 分清 so that 的两张面孔：目的（为了）与结果（因此）
- [ ] 会用 So do I 附和别人，并知道它和 So I do 的区别

## 语法详解

### 第 1 步：基本分工——so 管形容词副词，such 管名词

一句话记住：**so 是副词，修饰形容词和副词；such 修饰名词（短语）**。

| 结构 | 例句 | 中文 |
| --- | --- | --- |
| so + 形容词 | The movie was **so boring**. | 这电影太无聊了。 |
| so + 副词 | He drives **so fast**. | 他开车太快了。 |
| such + a/an + 形容词 + 单数名词 | She is **such a nice person**. | 她真是个好人。 |
| such + 形容词 + 复数名词 | They are **such kind people**. | 他们真是热心人。 |
| such + 形容词 + 不可数名词 | We had **such terrible weather**. | 我们赶上了糟糕透顶的天气。 |

判断口诀：后面**直接是名词**就用 such，后面是形容词或副词（名词还在更后面）就用 so。

```text
so  →  形容词 / 副词            （so beautiful / so quickly）
such →  (a/an + 形容词 +) 名词   （such a beautiful girl）
```

### 第 2 步：词序经典坑——so beautiful a girl

单数可数名词前有一个形容词时，出现两种都说得通的说法，词序却完全不同：

```text
✅ so beautiful a girl     （so 挤到最前面，a 被形容词甩在后面）
✅ such a beautiful girl   （such 待在 a 前面，一切按正常顺序）
❌ so a beautiful girl     （so 和 a 不能这样叠着放）
❌ such beautiful a girl   （such 后面必须先接 a/an 再接形容词）
```

对比着读三遍，让眼睛记住正确的形状：

- She is **so lovely a child** that everyone loves her. = She is **such a lovely child** that everyone loves her.（她是那么可爱的一个孩子，人人都喜欢她。）
- It is **so moving a story**. = It is **such a moving story**.（这是如此动人的一个故事。）

注意：这个"so + 形容词 + a + 名词"的倒装词序**只对单数可数名词开放**。复数和不可数名词没有 a/an，自然也没这个玩法，只能乖乖用 such：

- ❌ so kind people → ✅ **such kind people**
- ❌ so bad luck → ✅ **such bad luck**

考试就爱在四个选项里放 so beautiful a girl、such beautiful a girl、so a beautiful girl、such a beautiful girl——记住"只有第一个是对的"，这 1 分就稳了。

### 第 3 步：数量词的特殊待遇——so many / so much / so few / so little

按第 1 步的分工，many、much、few、little 后面接的是名词，似乎该用 such。但英语给数量词开了后门：**这四个词前面只能用 so，不能用 such**。

| 结构 | 例句 | 中文 |
| --- | --- | --- |
| so many + 复数名词 | I've never seen **so many** stars. | 我从没见过这么多星星。 |
| so much + 不可数名词 | There is **so much** noise outside. | 外面太吵了。 |
| so few + 复数名词 | He made **so few** mistakes. | 他犯的错这么少。 |
| so little + 不可数名词 | We have **so little** time. | 我们的时间这么少。 |

- ❌ such many people → ✅ **so many people**
- ❌ such much money → ✅ **so much money**

一个容易迷糊的点：little 有两个身份。表示"少"（数量，配不可数名词）时前面用 so；表示"小"（普通的形容词）时，就回到了普通规则，用 such：

- **so little money**（这么少的钱——little = 少）
- **such little children**（这么小的孩子——little = 小）

### 第 4 步：so...that 与 such...that——如此……以至于

"太……以至于发生某结果"用句型 so...that / such...that，that 后面接一个完整句子（结果）。词序规则和前面完全一样，只是加了个 that 尾巴：

| 句型 | 例句 | 中文 |
| --- | --- | --- |
| so + adj/adv + that | The box was **so heavy that** I couldn't lift it. | 箱子太重了，我抬不动。 |
| so + adj + a/an + n + that | It was **so hot a day that** we stayed inside all afternoon. | 天太热了，我们一下午都待在屋里。 |
| so many/much + n + that | There was **so much smoke that** we couldn't see the door. | 烟太大了，我们连门都看不见。 |
| such + (a/an + adj) + n + that | It was **such a cold night that** the lake froze. | 那晚太冷了，湖面都结冰了。 |

做题心法：先看 that 前面挂的是什么——挂形容词副词就 so，挂名词短语就 such，挂 many/much/few/little 一律 so。

### 第 5 步：so that 的两张面孔——目的 vs 结果

so that 合体后是另一个词：有时是"为了"（目的状语从句），有时是"因此"（结果）。判断靠两条线索：

| 线索 | 目的 so that（为了） | 结果 so that（因此） |
| --- | --- | --- |
| 从句动词 | 常带 can / could / may / might / will / would | 直接陈述已发生的事实 |
| 语气 | 还没发生，是"想达成" | 已经发生，是"导致的后果" |
| 标点 | 主从句之间一般不加逗号 | 前面常加逗号 |

看两组例句感受差别：

- I got up early **so that I could catch** the first bus.（我早起是为了赶上头班车。——目的：上车还没发生，从句用 could）
- It kept raining for a week, **so that many roads were closed**.（雨连下了一周，结果许多道路封闭了。——结果：封闭是既成事实）

补充：表结果时现代英语更常用单独的 so（It kept raining, **so** many roads were closed.），但考试阅读里 so that 表结果仍常出现，要认得。目的 so that 也可换成 in order that（更正式）：

- Speak louder **so that / in order that** everyone **can hear** you.（说大声点，好让大家都听得见。）

### 第 6 步：So do I——附和的倒装

别人说了一句话，你想说"我也是"，就用"so + 助动词/情态动词/be + 主语"的倒装：

- "I like this song." — "**So do I.**"（"我喜欢这首歌。"——"我也是。"）
- "He can swim." — "**So can I.**"（"他会游泳。"——"我也会。"）
- "They were late." — "**So were we.**"（"他们迟到了。"——"我们也是。"）

否定附和用 Neither / Nor 开头："-I don't like coffee. -**Neither do I.**"（我也不喜欢。）

注意助动词要和原句对齐：原句 likes 是第三人称单数，附和句就用 does（So does she）；原句是过去式 went，就用 did（So did I）。

这里还有一个经典对比：**So do I ≠ So I do**。

- **So do I.**（倒装，主语换人）= 我也是。
- **So I do.**（不倒装，主语不变）= 我确实如此（同意对方对我自己的描述）。
- "You cook very well." — "**So I do.**"（"你做饭很好吃。"——"可不是嘛。"）

倒装是 C1 的重头戏，这里先混个脸熟，[C1 第 3 课 · 省略与替代](../c1/unit-03.md)会系统展开。

### 第 7 步：such as 与 for example——举例的两副长相

- **such as + 名词（短语）**：只能接名词性的东西，不能接完整句子。
  - I like fruit, **such as** apples and bananas.（我喜欢水果，比如苹果和香蕉。）
  - Some languages, **such as** Italian, are easy to start with.（有些语言，比如意大利语，容易入门。）
- **for example + 句子或名词**：位置灵活（句首、句中、句末都行），可以接完整句子。
  - Many students work part-time. **For example**, Tom teaches swimming on weekends.（很多学生做兼职。比如汤姆，周末教游泳。）
  - Try a hobby—**for example**, painting.（找个爱好，比如画画。）

一句话：such as 后面"点名"，for example 后面可以"讲一件事"。

## 易混辨析

| # | ❌ 错误 | ✅ 正确 | 为什么 |
| --- | --- | --- | --- |
| 1 | such many books | **so many books** | many/much/few/little 是数量词，只配 so，不配 such——数量词特殊待遇 |
| 2 | so a beautiful girl | **so beautiful a girl** 或 **such a beautiful girl** | so 后面不能直接叠 a；要么形容词提到 a 前，要么改用 such 走正常词序 |
| 3 | such beautiful a girl | **such a beautiful girl** | such 后接单数可数名词时，a/an 必须紧跟 such，形容词放在 a 之后 |
| 4 | so terrible weather | **such terrible weather** | weather 不可数，前面没有 a/an 可供倒装，只能用 such |
| 5 | such little time | **so little time** | 这里的 little = "少"（数量），归数量词管，配 so；若 little = "小"（such little kids）才配 such |

再来一组"双面人"对比，练就火眼金睛：

| 句子 | so that 的身份 | 判断依据 |
| --- | --- | --- |
| She saved money so that she could buy a car. | 目的（为了买车） | 从句用 could，买车是还没实现的打算 |
| She sold her car, so that she had no way to work. | 结果（结果没法上班） | 前有逗号，从句陈述已发生的事实，无情态动词 |

## 实战练习

### 第一档 · 热身（单点直击）

1. The story was ______ moving that many people cried.（A. such　B. so　C. too　D. very）
2. It was ______ weather that we canceled the picnic.（A. so bad a　B. such bad　C. such a bad　D. so bad）
3. I have never seen ______ people in one place.（A. so much　B. such many　C. so many　D. such much）
4. ______ little money is not enough for the trip.（A. Such　B. So　C. A such　D. A so）
5. She is ______ honest girl that everyone trusts her.（A. so　B. so an　C. such　D. such an）

### 第二档 · 标准（考试风格）

6. It was ______ interesting lecture that nobody fell asleep.（A. so　B. such an　C. such a　D. so an）
7. There was ______ smoke in the room that we had to open all the windows.（A. such many　B. so many　C. so much　D. such much）
8. He ran ______ fast that no one could catch up with him.（A. such　B. so　C. too　D. more）
9. It was ______ a boring speech ______ half the audience left early.（A. so; that　B. such; that　C. so; as　D. such; which）
10. Bring the map ______ we can find the small town without asking the way.（A. so that　B. such that　C. in order to　D. so as）
11. It kept snowing for days, ______ the roads were all blocked.（A. so that　B. in order that　C. so as to　D. for）
12. — I really like the food here. — ______.（A. So I do　B. So do I　C. So I like　D. Neither do I）
13. — Your daughter speaks English very well. — ______.（A. So she does　B. So does she　C. So do I　D. Neither does she）

### 第三档 · 挑战（语境综合）

14. 改错：The teacher gave us such many exercises that we had no time to play.
15. 用两种方式翻译"她是如此聪明的一个女人，以至于人人都愿意向她求助"：用 so 开头一种，用 such 开头一种。

## 练习答案

1. **B**。moving 是形容词（感人的），so + 形容词；such 不能直接修饰形容词。
2. **B**。weather 不可数名词，such + 形容词 + 不可数名词；没有 a 可言，A、C 结构不成立。
3. **C**。people 是复数名词，many 是数量词，数量词前只配 so（so many）。
4. **B**。这里 little = "少"（little money 钱这么少），是数量词待遇，用 so。
5. **D**。honest 以元音音素开头，such an honest girl；若用 so 则要说 so honest a girl，选项中没有。
6. **B**。lecture（讲座）是单数可数名词，interesting 以元音音素开头，such an interesting lecture；so an 是错误词序。
7. **C**。smoke 不可数，much 是数量词，so much smoke。
8. **B**。fast 是副词（跑得快），so + 副词。
9. **B**。speech 是单数可数名词用 such a，"如此……以至于"接 that：such a boring speech that...
10. **A**。带地图的目的是"能找到小镇不问路"，从句有情态 can，so that 表目的；C、D 后面要接动词原形不能接句子。
11. **A**。前面有逗号，"道路全被封"是既成事实，so that 表结果。
12. **B**。"我也喜欢（这里的菜）"，主语换人，用倒装 So do I。
13. **A**。夸的是"你女儿"，回答"她确实如此"，主语不变，不倒装用 So she does。
14. such many → **so many**。many 是数量词，只配 so：The teacher gave us so many exercises that we had no time to play.
15. **She is so clever a woman that everyone is willing to turn to her for help.** / **She is such a clever woman that everyone is willing to turn to her for help.** 注意 so 版里形容词 clever 提到 a 前面，such 版按正常顺序。
