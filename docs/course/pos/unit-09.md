## 本课目标

学完这一课，你可以做到：

- [ ] 看懂 care → careful → carefully → carelessness 的家族变身链
- [ ] 看到 -er / -tion / -ness 立刻猜出"这是名词"
- [ ] 看到 -ful / -less / -y 猜出"这是形容词"，看到 -ly 猜出"这是副词"
- [ ] 知道前缀 un-（不）、re-（再次）、dis-（否定）的意思
- [ ] 说出为什么背单词要按家族背，并知道这是将来词根词缀课的第一块砖

## 词性讲解

### 第一步：一个单词的家族

一个词根可以像孙悟空一样变身。看 care 家族：

```text
care (v. 关心)
 ├─ + ful → careful (adj. 小心的)         "有小心这个特点"
 │    └─ + ly → carefully (adv. 小心地)   "以小心的方式"
 └─ + less → careless (adj. 粗心的)       "没有小心"
      └─ + ness → carelessness (n. 粗心)  "粗心这种毛病"
```

四个词，一棵树，词性和意思全部连着变。这就是**构词法**（word formation，造单词的方法）：**词根负责意思，词缀负责变身**。

先解释两个术语：**词根**是家族的本体（care），**词缀**是加在它身上的小零件。词缀分两种：

- **后缀**（加在词尾）：主要功能是**换词性**——本课主角
- **前缀**（加在词头）：主要功能是**改意思**——本课配角

中文对照：汉字有偏旁部首，"氵"旁的字多半和水有关；英语有词根词缀，-ly 结尾的词多半是副词。你早就在用同样的方法认汉字了，现在把它搬到英语上，一模一样。

### 第二步：名词后缀——看到它们，就是名词

| 后缀 | 意思 | 变身例 | 例句 |
|---|---|---|---|
| -er / -or | 做这个动作的人或东西 | teach → teach**er**（老师） | My **teacher** is very kind. 我的老师很和气。 |
| | | work → work**er**（工人） | My father is a work**er**. 我爸爸是工人。 |
| -tion | 动作的过程、结果（预告） | act → act**ion**（行动） | We need action, not words. 我们需要行动，不是空话。 |
| -ness | 把形容词变成"这种状态" | happy → happi**ness**（快乐） | Money can't buy **happiness**. 钱买不到快乐。 |

注意两个小机关：happy 变 happiness 时 y 变 i（happy + ness → happiness）；-tion 是个大户，act、invent 一大串动词都靠它变名词，深挖留给以后的词根课。

### 第三步：形容词后缀——描述"怎么样的"

| 后缀 | 意思 | 变身例 | 例句 |
|---|---|---|---|
| -ful | 充满……的（有） | help → help**ful**（有帮助的） | This book is very **helpful**. 这本书很有帮助。 |
| -less | 没有……的（无） | use → use**less**（没用的） | An empty box is **useless**. 空盒子没用。 |
| -y | 有……特点的 | rain → rain**y**（下雨的） | It is a **rainy** day. 今天是雨天。 |
| | | wind → wind**y**（有风的） | It is **windy** today. 今天风大。 |

**有/无一对，正好相反**：useful（有用的）↔ useless（没用的）；careful（小心的）↔ careless（粗心的）。第 4 课见过 -ful / -less 的脸，今天正式入伙。背一个后缀，收一双词。

### 第四步：副词后缀——ly，方式的标签

| 后缀 | 变身例 | 例句 |
|---|---|---|
| -ly | slow → slow**ly**（慢慢地） | Please speak **slowly**. 请慢点说。 |
| | quick → quick**ly**（快速地） | He runs **quickly**. 他跑得快。 |

规则：形容词 + ly = 副词，表示"以某种方式做"。

例外确认（第 5 课讲过）：**fast 和 hard 本身既是形容词也是副词**（a fast car 一辆快车 / run fast 跑得快；work hard 努力工作），不加 -ly。别给它们硬穿军装。

### 第五步：基础前缀——改意思的小帽子

| 前缀 | 意思 | 变身例 | 例句 |
|---|---|---|---|
| un- | 不、相反 | happy → **un**happy（不快乐的） | Why are you **unhappy**? 你为什么不开心？ |
| re- | 再次、重新 | do → **re**do（重做） | Please **redo** your homework. 请重做你的作业。 |
| dis- | 否定（轻讲） | like → **dis**like（不喜欢） | I **dislike** rainy days. 我不喜欢雨天。 |

前缀只改意思，一般不改词性：unhappy 还是形容词，redo 还是动词。词性看什么？看后缀、看位置——下面三练。

### 第六步：见后缀知词性（三练）

三秒判断，不用查词典：

- 看到 **-ly** → 想副词：slowly、quickly、carefully
- 看到 **-ful / -less / -y** → 想形容词：helpful、useless、rainy
- 看到 **-er / -tion / -ness** → 想名词：teacher、action、happiness

这就是构词法送你的第一副眼镜：第 8 课总结表里那列"标志后缀"，从今天起全部兑现。

### 第七步：为什么这很重要

1. **查词典不再懵**。词典里 n. = 名词、v. = 动词、adj. = 形容词、adv. = 副词，这些缩写只是词性标签。以前看它们像天书，现在你连词带标签一起认识。
2. **背单词效率翻倍**。背会 care 一个词根，careful、carefully、carelessness 一串全带走。按家族背，不是按字母表背。
3. **为词根课打地基**。本课只讲了几个最基础的后缀；B2 阶段有完整的[词根词缀课](../roots/index.md)，那才是英语"偏旁部首"的全套体系。本课是走上那座桥的第一块砖——桥头堡先修好，大军将来才过得去。

识别三招（构词版）：

- **看形态**（最重要）：词尾 -er / -tion / -ness → 名词；-ful / -less / -y → 形容词；-ly → 副词
- **看位置验证**：名词常站在动词后或 the / a 后；形容词站在名词前；副词常守在动词旁
- **看意思辅助**：说"人、东西"的 -er 多是名词；说"方式"的 -ly 多是副词

## 中文母语者常见误区

| ❌ 错误 | ✅ 正确 | 为什么 |
|---|---|---|
| slow → slowlly，care → carefull | slow**ly**，care**ful** | 拼写细节：slow 直接加 ly；care 加 ful 只有一个 l，不是 carefull |
| 所有副词都以 -ly 结尾 | fast、hard 也是副词 | run fast、work hard 都对，不能说 fastly；hardly 是另一个词（"几乎不"，B2 再见） |
| 见到 -er 一定是名词 | bigg**er** 不是名词 | 形容词加 er 还可能是比较级（big → bigger"更大"），语法课深讲。见到 -er 先问：是"人/东西"还是"更"？ |
| unhappy 拆成 un + happy，以为是动词 | unhappy 还是形容词 | 前缀只改意思不改词性。词性看后缀和位置，不看帽子 |
| 生词一个一个死记 | 先拆零件再记 | action = act + tion，一看就是"行动"变名词。拆开认，比死记快十倍 |

## 练习

### 热身（第 1~3 题）

**1.** 家族连线：把左边的词根和右边它的家族成员连起来（每个只用一次）：

```text
teach · · · happiness
help  · · · rainy
happy · · · teacher
rain  · · · carefully
slow  · · · helpful
care  · · · slowly
```

**2.** 说出变身零件：careful 是 care + ______？carefully 是 careful + ______？carelessness 是 careless + ______？

**3.** 三秒判断：-ly 结尾多半是什么词性？-ful 呢？-er 呢？

### 标准（第 4~9 题）

**4.** 判断词性（用缩写 n. / v. / adj. / adv.）：

- (a) singer
- (b) sunny
- (c) quickly
- (d) useful
- (e) kindness
- (f) useless

**5.** 有/无配对：写出 useful 的反义词、careful 的反义词。

**6.** 拆零件猜意思（大胆猜）：

- (a) windy
- (b) worker
- (c) unhappy

**7.** 前缀侦查：说出前缀和意思：

- (a) unlike → like 的 ______（un- = ______）
- (b) rewrite → write 的 ______（re- = ______）

**8.** 例外警报：run fast 里的 fast 是什么词性？要改成 fastly 吗？

**9.** 词典练习：查一下 play 加 -er 是什么词，抄下词性和意思。

### 挑战（第 10~12 题）

**10.** 亲手造一条变身链：用 care 造"动词 → 形容词 → 副词"三步链，写出来。

**11.** 再造一条反义链：用 use 造"形容词（有用的）↔ 形容词（没用的）"一对反义词。

**12.** 小老师题：用一句中文向家人解释"为什么背会 care 一个，等于背会四个词"。

## 练习答案

<details><summary>点击查看答案</summary>

**1.** teach ↔ teacher；help ↔ helpful；happy ↔ happiness；rain ↔ rainy；slow ↔ slowly；care ↔ carefully

**2.** care + **ful**；careful + **ly**；careless + **ness**

**3.** -ly → 副词；-ful → 形容词；-er → 名词（但注意比较级，见误区表）

**4.** (a) singer n.（-er）；(b) sunny adj.（-y）；(c) quickly adv.（-ly）；(d) useful adj.（-ful）；(e) kindness n.（-ness）；(f) useless adj.（-less）

**5.** useful ↔ **useless**；careful ↔ **careless**（-ful 有、-less 无，一对双胞胎）

**6.** (a) windy：wind 风 + y，形容词"有风的"；(b) worker：work 工作 + er，名词"工人"；(c) unhappy：un 不 + happy 快乐，形容词"不快乐的"

**7.** (a) unlike 是 like 的否定（un- = 不）；(b) rewrite 是 write 的"再写一遍"（re- = 再次）

**8.** fast 是副词（也是形容词），不能改成 fastly。fast 和 hard 是"不加 -ly 的副词"，第 5 课讲过

**9.** player，n.，"运动员；播放器"（-er 徽章兑现）

**10.** care（v. 关心）→ careful（adj. 小心的）→ carefully（adv. 小心地）

**11.** useful（有用的）↔ useless（没用的）

**12.** 参考话术：care 是家族本体，加 -ful 变形容词 careful，再加 -ly 变副词 carefully，加 -less / -ness 又得到 careless 和 carelessness。意思一条线，背一个带四个
