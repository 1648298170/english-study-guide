## 这门课解决什么问题

一句话：**长难句读不懂，不是词不认识，是结构看不清。**

一个句子三十个词，单词全认识，读完还是一头雾水。因为英语习惯"先说结论，再挂配件"，中文习惯"配件在前，结论收尾"——两种语言的骨架装反了，硬读自然累。

句子拆解课不重新教语法规则，只教一件事：**把任何英语句子拆成"主干 + 配件"，再把意思按中文习惯装回去。**

什么时候学最划算？**B1 学完之后**（对应学习框架阶段 3~4）：

- 想读外刊、原版书——每天拦住你的就是长难句
- 想考四六级、考研、雅思——长难句就是阅读和翻译的主战场
- 语法规则已经学过一遍——现在缺的不是规则，是把规则用起来的"手上功夫"

## 一句话方法论

**数谓语 → 切连词 → 找主干 → 挂配件 → 调语序**

像收拾一间乱屋子：

1. **数谓语**：每个谓语是一根顶梁柱。几个谓语，就有几个分句。
2. **切连词**：that / which / when / because / and …… 都是"隔断墙"，顺着切。
3. **找主干**：主句的"谁干了什么"浮出水面。
4. **挂配件**：定语、状语、插入语——全是挂在主干上的挂钩，跑不掉。
5. **调语序**：按中文习惯重排——定语前移、状语前置、化整为零。

## 怎么上这门课（上课程式）

每课四拍，缺一不可：

| 拍 | 做什么 | 时间 |
|---|---|---|
| 1. 学方法 | 读懂"核心方法"，跟着判断流程走一遍 | 30 分钟 |
| 2. 看示范 | 例句拆解逐行看，看懂每一行为什么这么标 | 30 分钟 |
| 3. 自己拆 | 实战练习先拆后译，卡住也不偷看答案 | 2~3 小时 |
| 4. 对答案 | 错题把答案的拆解步骤**抄一遍**——手上记，比眼里看牢十倍 | 1 小时 |

错题不抄，等于白错。拆解是肌肉记忆，不是知识。
