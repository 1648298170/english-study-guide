> ⏱ 预计 4~6 小时，建议拆成 3 天完成 | 前置：[第 10 课 · 综合实战](./unit-10.md) | 难度：B1+（拆句课 · 中译英篇）

前十课，你一直在把英语拆成中文：数谓语、切分句、找主干、挂配件。从这一课起，**手术刀反过来用**——英译中是拆解，中译英是组装。拆解只需要看懂，组装却要你亲手把每一个零件造出来，还要按英语的图纸装。这是很多同学"看得懂、写不出"的根源，也是本课要治的病。

## 本课目标

- [ ] 能说清英译中与中译英的本质区别（拆解 = 理解，组装 = 输出）
- [ ] 拿到中文句子，第一反应是删掉修饰、挖出主干，而不是逐词开译
- [ ] 会用五大句型决策表，给主干配上正确的英语骨架
- [ ] 会用时态显化决策树处理"了 / 过 / 将"，能识破没有"被"字的语义被动
- [ ] "随着……/ 越来越……/ 据说……"这些中文特色结构，张口就有对应句型

## 核心方法

### 英译中 vs 中译英：同一把手术刀，两个方向

英译中像修表师傅拆表：零件是人家造好的，你只要拆开、看清、按中文习惯装回去。中译英像自己造表：中文给你一张效果图，你得从骨架开始搭。

| 第 9 课（英译中 · 拆解） | 本课（中译英 · 组装） |
| --- | --- |
| 定语前移律：后置定语搬到名词前 | 定语后置：名词前的"……的"变回短语 / 从句，挂到名词后 |
| 状语前置律：句尾状语提到中文句首 | 状语归位：中文句首状语收回英语句尾（或保留置首） |
| 时态显化律：补出"了 / 过 / 将" | 时态显化：靠"了 / 过 / 将"和语境决定动词形态 |
| 被动转主动：能躲"被"就躲 | 语义被动时主动转被动：补出 be done |
| 化整为零：英语长句切成中文短句 | 合并四法：中文短句拼成英语长句 |

先记住一个数字：**中译英的错误，一半来自"没想清主干就动笔"。** 逐词顺着中文语序往外倒，倒出来的必然是中式英语。所以本课五步法的第一步，就是先把修饰全部删光。

### 中译英五步法详解

```
第①步  找中文主干（谁 + 干什么 / 是什么——先删掉所有修饰只留核心）
第②步  选英语句型（主干套进五大句型之一）
第③步  定时态语态（把中文藏起来的时态、语态显化出来）
第④步  挂修饰（定语后置、状语归位——和中文语序反着来）
第⑤步  检查四项（时态一致 / 单复数 / 冠词 / 搭配）
```

一句话记住：**一挖主干、二选句型、三定时态、四挂修饰、五查细节。**

先完整走一遍：

```
原句  随着互联网的发展，越来越多的人喜欢网上购物。
第①步  中文主干：越来越多的人 喜欢网上购物
第②步  句型选择：主谓宾（More and more people like ...）
第③步  时态语态：一般现在时（习惯性现象）
第④步  挂修饰：随着互联网的发展 → With the development of the Internet（介短作状语置首）
第⑤步  检查：名词单复数/冠词/搭配
译文  With the development of the Internet, more and more people like shopping online.
```

注意第①步发生了什么："随着互联网的发展"被整个删掉了——它是背景状语，不是主干；"越来越"也被删掉了——它是修饰。剩下的"人 + 喜欢 + 购物"才是句子的心脏。心脏定了，其余零件才有地方挂。

### 第①步详解：找中文主干

拿手把整句遮住，只露头尾，问两个问题：**谁？干什么 / 是什么？** 把"的、地、在、随着、为了、据说"开头的成分全部视为候选修饰，先删后验。

> 那本我上周在书店买的书非常有用。
> 删：那本 / 我上周在书店买的 → 剩：书 + 有用。主干到手。

两个提醒：

- **中文爱省主语。**"下雨了""该走了"没有主语，先补出 it，再进第②步。
- **删掉的成分不是扔掉**，是放进"待挂区"，第④步会逐个领回去。

### 第②步详解：选英语句型（五大句型决策表）

主干有了，接下来配骨架。别凭感觉，查表：

| 中文主干长什么样 | 英语句型 | 骨架 | 示例 |
| --- | --- | --- | --- |
| 谁 **是什么 / 怎么样** | 主系表 | S + be / 感官动词 + 表 | 这本书很有趣 → This book is interesting. |
| 谁 **干什么**（及物） | 主谓宾 | S + V + O | 他每天学英语 → He studies English every day. |
| 谁 **给谁什么 / 教谁什么** | 主谓双宾 | S + V + 间宾 + 直宾 | 她教我数学 → She teaches me math. |
| 谁 **使什么怎样** | 主谓宾补 | S + V + O + C | 这个消息让我们很高兴 → The news made us happy. |
| 谁 **动作本身说完了**（不及物） | 主谓 | S + V (+ 状语) | 他昨天到了 → He arrived yesterday. |

决策口诀：问宾语——没有宾语看是不是"是什么"，有宾语再看"宾语后面还有没有补充说明"。90% 的中文主干，都能在这五行里对号入座。

### 第③步详解：定时态语态（显化决策树）

中文动词不变形，时态全靠"了 / 过 / 将 / 在 / 正"和语境暗示；英语动词必须变。逐条过下面这棵树：

- 句中有 **"过 / 曾经"** → 一般过去时（或与现在挂钩时用完成时）
- 句中有 **"了"** → 先分清两种"了"：
  - **动作完成**（吃了饭、完成了任务）→ 过去时或完成时
  - **状态变化**（他是老师了、我明白了）→ "已经"义，动词本身未必过去
- 句中有 **"将 / 要 / 会"** → 将来时
- 句中有 **"正在 / 在 / 着"** → 进行时
- 句中是 **习惯、反复、真理**（每天、通常、总是）→ 一般现在时
- 全段是 **过去叙事** → 整段动词跟着过去

**有"了"未必过去**，这是最大的坑。"他是老师了"不能译成 He was a teacher——他现在还是。反过来，语境是过去的事，哪怕中文没写"了"，英语也得过去时。

语态的坑更隐蔽：**中文没有"被"字，语义却是被动**。自查一招——看主语和动词的关系：

> 桥修好了。（桥不会自己修 → 被动）The bridge has been repaired.
> 作业写完了。The homework has been finished.
> 这个问题解决了。This problem has been solved.

主语是"受事"（被动作影响的东西），英语就上 be done。中文满街都是这种无标记被动，考试最爱考。

### 第④步详解：挂修饰（重排规则表）

骨架立好，把"待挂区"里的修饰逐个领回去——**位置基本和中文相反**：

| 修饰类型 | 中文位置 | 英语位置 | 示例 |
| --- | --- | --- | --- |
| 定语（"……的"） | 名词前 | 一两个词前置；短语 / 从句后置 | 我昨天买的书 → the book (I bought yesterday) |
| 时间状语 | 句首或动词前 | 句尾为主（也可置首强调） | 我昨天见到他了 → I met him yesterday. |
| 地点状语 | 动词前或句首 | 句尾（多个时"地点在前、时间在后"） | 他在图书馆学习 → He studies in the library. |
| 方式状语 | 动词前 | 动词后 | 他认真地写 → He writes carefully. |
| 背景 / 伴随（随着、因为） | 句首 | With / As 短语置首，或从句 | 随着经济的发展 → With the development of the economy |
| 目的（为了） | 句首 | to do 置首或句尾 | 为了赶上火车 → to catch the train |

第 9 课的"定语前移律、状语前置律"现在全部反着用：**英译中把修饰往前挪，中译英把修饰往后挪。** 方向换了，规则没换。

### 第⑤步详解：检查四项

交卷前固定过四道闸：

1. **时态一致**：全段时态统一了吗？从句时态跟主句协调吗？
2. **名词单复数**：可数名词裸奔了吗（books、customers）？
3. **冠词**：泛指单数有没有 a / an？特指有没有 the？
4. **搭配**：动词和名词是英语夫妻吗（learn knowledge ✗ → gain knowledge ✓）？

这四项覆盖了中式英语错误的大半。写完别急着合上本子，逐项扫一遍。

### 中文特色结构的转换（高频表）

以下结构在中文里出现频率极高，且各有固定英语通道，值得整表背下：

| 中文结构 | 英语处理 | 示例 |
| --- | --- | --- |
| 随着…… | With + 名词短语 / As + 句子 | 随着经济的快速发展 → With the rapid development of the economy |
| 越来越…… | more and more + 形容词 / 名词；-er and -er | 越来越重要 → more and more important；越来越快 → faster and faster |
| ……的是…… | 强调句 It is ... that ... | 吸引我的是它的设计 → It is its design that attracts me. |
| 据说 / 人们认为…… | It is said / believed that ... | 人们认为健康最重要 → It is believed that health matters most. |
| 无主句：下雨了 | It is raining | 下雨了 → It is raining. |
| 无主句：该走了 | It's time to do | 该走了 → It's time to go. |
| 要想……就必须…… | To ..., one must ... / If you want to ..., you must ... | 要想通过考试就必须努力 → To pass the exam, you must work hard. |

"随着"给两条通道：后面跟的是名词就用 With，跟的是完整句子就用 As。As e-commerce develops rapidly 和 With the rapid development of e-commerce 是同一句话的两件外衣。

### 中文多短句 → 英语长句：合并四法

中文是流水句，短句一句接一句，逗号连到底；英语是一棵树，先有主句树干，再往外长枝。中译英遇到三四个短句连发，**先定主句，其余短句降级**：

| 降级方式 | 把短句变成 | 示例 |
| --- | --- | --- |
| 并列 | and / but 串成平级分句 | 天黑了，我们就回家了。→ It got dark, and we went home. |
| 从句 | when / because / which 从句 | 我到站时，火车已经开走了。→ When I got to the station, the train had left. |
| 分词 | doing / done 短语 | 他坐在角落里，安静地看书。→ He sat in the corner, reading quietly. |
| 介词短语 | with / in / by 短语 | 因为下雨，比赛取消了。→ Because of the rain, the game was canceled. |

实战演示：

> 他 2015 年大学毕业。毕业后他去了深圳。在深圳他进了一家科技公司。
> 定主句：他进了科技公司 → He joined a technology company.
> 其余降级：毕业后去了深圳 → 时间线并进 after；大学毕业 → 分词
> 合并：After graduating in 2015, he moved to Shenzhen and joined a technology company.

三个短句并成一句，信息一个不少，这就是"手术刀反过来用"的威力。并列结构的刀法细节见[第 3 课](./unit-03.md)；英语句式怎么变着花样组装，写作课会再深挖（[写作课 · 句式多样化](../writing/unit-07.md)）。

## 例句拆解示范

五句组装，从最短到考试级，场景覆盖日常、职场、社会话题。

### 示范 1 · 热身（日常 · 主系表 + 主谓宾）

```
原句  这本书很有趣，我已经读了三遍。
第①步  中文主干：书 有趣；我 读了（书）三遍
第②步  句型选择：主系表（This book is ...）+ 主谓宾（I have read it ...）
第③步  时态语态：前半一般现在时（性质描述）；后半现在完成时（"已经……了"，动作完成且与现在相连）
第④步  挂修饰：这 → this 置前；三遍 → three times 置尾；已经 → already（完成时已含，可留可省）
第⑤步  检查：第二句用 it 指代 book 避免重复；times 用复数
译文  This book is very interesting. I have already read it three times.
```

看点：两个短句信息平等、没有主次，就保留两个独立句，不必硬合并——合并是"需要有树"时才用。

### 示范 2 · 标准（职场 · 过去时 + 状语置首）

```
原句  会议结束后，经理把新方案发给了每一位员工。
第①步  中文主干：经理 发给（员工）方案
第②步  句型选择：主谓宾 + to 短语（send sth to sb）
第③步  时态语态：一般过去时（"了"，已完成的动作）
第④步  挂修饰：会议结束后 → After the meeting 置首；新 → new；每一位 → every
第⑤步  检查：send 过去式 sent；every + 单数 employee；冠词 the plan
译文  After the meeting, the manager sent the new plan to every employee.
```

看点："把字句"是中文特色，英语没有"把"——直接 send + 宾语 + to + 人，第②步就要把这个通道想好。

### 示范 3 · 标准（日常 · 定语从句后置）

```
原句  那个昨天帮我修电脑的工程师来自一家德国公司。
第①步  中文主干：工程师 来自 公司
第②步  句型选择：主系表（be from 表归属状态）
第③步  时态语态：一般现在时（"来自"是状态，不是动作）
第④步  挂修饰：那个昨天帮我修电脑的 → (who helped me repair my computer yesterday) 定语从句后置；一家 → a；德国 → German 前置
第⑤步  检查：help sb do sth 搭配；German 首字母大写
译文  The engineer who helped me repair my computer yesterday is from a German company.
```

看点：中文 9 个字的定语压在名词前，英语必须整包搬到名词后——这是第④步重排规则表的招牌动作。硬要前置（the yesterday helped-me-repair-computer engineer）就是灾难现场。

### 示范 4 · 挑战（社会话题 · 据说 + 越来越）

```
原句  据说，越来越多的年轻人喜欢在网上购物，因为网上的东西更便宜。
第①步  中文主干：年轻人 喜欢 网上购物
第②步  句型选择：主谓宾（like shopping online）；据说 → It is said that 置首；因为 → because 从句
第③步  时态语态：一般现在时（习惯性现象，全句无过去标记）
第④步  挂修饰：越来越多 → more and more 前置；据说 → It is said that；"网上的东西更便宜"降级为 because 从句
第⑤步  检查：shopping online 搭配；things 复数；cheaper 比较级
译文  It is said that more and more young people like shopping online because things there are cheaper.
```

看点：中文三个短句，组装后一棵树——It is said that 是树冠，主句是树干，because 从句是枝。"据说"通道（It is said that）考试出现率极高，务必形成条件反射。

### 示范 5 · 挑战（考试级 · 随着 + 现在进行时）

```
原句  随着电子商务的快速发展，传统零售业正面临前所未有的挑战。
第①步  中文主干：零售业 面临 挑战
第②步  句型选择：主谓宾（face 及物动词，直接带宾语）
第③步  时态语态：现在进行时（"正"字亮灯）
第④步  挂修饰：随着电子商务的快速发展 → With the rapid development of e-commerce 介短置首；传统 → traditional；前所未有的 → unprecedented 前置
第⑤步  检查：traditional retail 不可数 → is facing；challenges 复数；e-commerce 拼写
译文  With the rapid development of e-commerce, traditional retail is facing unprecedented challenges.
```

看点："随着"的 With 通道 + "正"的进行时，是四六级翻译开头的高频组合。同一个意思还能走 As 通道：As e-commerce develops rapidly, ...——两条通道，随时切换。

## 中文学习者常见误区

| ❌ 错误做法 | ✅ 正确做法 | 为什么 |
| --- | --- | --- |
| 顺着中文语序逐词翻译 | 第①步先删修饰挖主干，再组装 | 中文定语前置、状语前置，照抄语序必出中式英语（the yesterday helped me engineer 式灾难） |
| 见"了"就写过去时 | 先分动作完成还是状态变化，再看语境 | "他是老师了"不是过去时；语境是过去的事，没"了"也得过去 |
| "下雨了 / 该走了"硬找主语逐字译 | 无主句走 it 通道：It is raining / It's time to go | 中文可以没有主语，英语句子没有主语就立不住 |
| 中文没写"被"就想不到被动 | 检查主语是不是受事：桥修好了 → has been repaired | 无标记被动是中文常态，也是考试最爱埋的雷 |
| 三个短句译成三个独立句 | 定主句，其余降级为从句 / 分词 / 介短 | 中文流水句直译成英语，句间逻辑全丢，读起来像小学生造句 |

## 实战练习

任务统一：按组装五步完整走（原句 → 主干 → 句型 → 时态 → 挂修饰 → 检查 → 译文）。

**热身（10~15 字短句，找回组装手感）**

1. 我哥哥在一家银行工作。
2. 昨天下了一整天的雨。
3. 这道菜闻起来很香。

**标准（含从句结构，20~30 字）**

4. 那个站在门口的年轻人是我们新来的英语老师。
5. 会议取消的消息让所有员工都很惊讶。
6. 我永远忘不了我第一次来北京的那一天。
7. 为了赶上一早的火车，他五点就起床了。

**挑战（四六级风格复合句，30~40 字）**

8. 随着人们生活水平的提高，旅游已经成为许多人节假日放松自己的主要方式。
9. 据说这座寺庙始建于唐朝，几百年来一直在吸引着来自世界各地的游客。
10. 要想在这家大公司找到一份理想的工作，你就必须同时具备良好的英语能力和团队合作精神。

```
第②步  句型选择：主谓（work 不及物）+ 地点状语
第③步  时态语态：一般现在时（职业状态）
第④步  挂修饰：在一家银行 → in a bank 置尾；我 → my
第⑤步  检查：冠词 a 不能漏；brother 拼写
译文  My brother works in a bank.
```

易错点：in bank 漏冠词是最高频扣分点；第三人称单数 works 别丢 s。

**2.**

```
原句  昨天下了一整天的雨。
第①步  中文主干：（无主句）下雨
第②步  句型选择：it 天气句（It rained ...）
第③步  时态语态：一般过去时（"昨天"锁定过去）
第④步  挂修饰：一整天 → all day；昨天 → yesterday 置尾
第⑤步  检查：all day 前不加 for；It 大写开头
译文  It rained all day yesterday.
```

易错点："下了"误用完成时 It has rained——有明确过去时间词（yesterday）时用过去时；无主句硬造主语 The rain down 是灾难。

**3.**

```
原句  这道菜闻起来很香。
第①步  中文主干：菜 闻起来 香
第②步  句型选择：主系表（smell 感官系动词 + 形容词）
第③步  时态语态：一般现在时（当下感受）
第④步  挂修饰：这道 → this；很 → very
第⑤步  检查：smells 后接形容词 good，不接副词 well
译文  This dish smells very good.
```

易错点：smells well 是经典错误——well 是副词，感官系动词后要形容词。

**4.**

```
原句  那个站在门口的年轻人是我们新来的英语老师。
第①步  中文主干：年轻人 是 老师
第②步  句型选择：主系表
第③步  时态语态：一般现在时（介绍现状）
第④步  挂修饰：站在门口的 → (who is) standing at the door 定语后置；我们新来的英语 → our new English 前置
第⑤步  检查：our 后不再加 the；词序 new English teacher
译文  The young man standing at the door is our new English teacher.
```

易错点：定语从句 / 分词必须搬到 man 后面；前置直译 the standing at the door young man 是语序灾难。

**5.**

```
原句  会议取消的消息让所有员工都很惊讶。
第①步  中文主干：消息 让 员工 惊讶
第②步  句型选择：主谓宾（surprise 作动词）+ 同位语从句挂 news
第③步  时态语态：一般过去时（消息已发生）；"取消"早于"惊讶"且是被动 → 过去完成被动
第④步  挂修饰：会议取消的 → that the meeting had been canceled 同位语从句后置；所有 → all
第⑤步  检查：all the employees；surprised 过去式
译文  The news that the meeting had been canceled surprised all the employees.
```

易错点："A 的消息"后接内容时用 that 同位语从句，不用 which 定语从句；中式直译 the meeting canceled news let all staff very surprised 满盘皆输。

**6.**

```
原句  我永远忘不了我第一次来北京的那一天。
第①步  中文主干：我 忘不了 那一天
第②步  句型选择：主谓宾 + when 定语从句挂 day
第③步  时态语态：将来时否定（will never forget，指向未来的持续状态）
第④步  挂修饰：永远 → never；我第一次来北京的 → when I first came to Beijing 定语从句后置
第⑤步  检查：never 已含否定，不再加 not；forget 直接接名词
译文  I will never forget the day when I first came to Beijing.
```

易错点：the day 后的 when 不能换成 which（when 在从句中作时间状语，不作主宾语）。

**7.**

```
原句  为了赶上一早的火车，他五点就起床了。
第①步  中文主干：他 起床
第②步  句型选择：主谓（get up）+ 不定式目的状语
第③步  时态语态：一般过去时（"了"，已发生）
第④步  挂修饰：为了赶上一早的火车 → To catch the early train 置首；五点 → at five；就（早）→ in the morning 补足
第⑤步  检查：catch 过去式 caught；"就"的早意可由 early train + 五点整点自带
译文  To catch the early train, he got up at five in the morning.
```

易错点："为了"用 to do 还是 for？接动词用 to do，接名词用 for；got up 过去式别写 get up。

**8.**

```
原句  随着人们生活水平的提高，旅游已经成为许多人节假日放松自己的主要方式。
第①步  中文主干：旅游 成为 方式
第②步  句型选择：主谓宾（has become + 宾语）+ to do 定语挂 way
第③步  时态语态：现在完成时（"已经"）
第④步  挂修饰：随着人们生活水平的提高 → With the improvement of people's living standards 介短置首；许多人的、节假日、放松自己的、主要的 → for many people / during holidays / to relax themselves / main
第⑤步  检查：traveling 动名词作主语；living standards 复数惯用
译文  With the improvement of people's living standards, traveling has become the main way for many people to relax themselves during holidays.
```

易错点："随着"通道二选一（With 短语 / As 句子）；"放松自己" relax themselves 在考试里可直接 relax，更简洁。

**9.**

```
原句  据说这座寺庙始建于唐朝，几百年来一直在吸引着来自世界各地的游客。
第①步  中文主干：寺庙 始建于唐朝；寺庙 吸引 游客
第②步  句型选择：It is said that + 被动句 + and 并列完成进行句
第③步  时态语态：始建于 → 一般过去时被动（was built）；几百年来一直在吸引着 → 现在完成进行时（has been attracting）
第④步  挂修饰：据说 → It is said that 置首；几百年来 → for hundreds of years 置尾；来自世界各地的 → from all over the world 后置
第⑤步  检查：the Tang Dynasty 朝代名大写；visitors 复数；hundreds of 加 s
译文  It is said that this temple was first built in the Tang Dynasty and has been attracting visitors from all over the world for hundreds of years.
```

易错点："始建于"是典型无标记被动，主谓必须翻成 was first built；"一直在……着"对应完成进行时，别丢 been。

**10.**

```
原句  要想在这家大公司找到一份理想的工作，你就必须同时具备良好的英语能力和团队合作精神。
第①步  中文主干：你 必须 具备 能力（和精神）
第②步  句型选择：To do 目的状语 + you must have ...（要想……就必须……通道）
第③步  时态语态：情态动词 must + 动词原形
第④步  挂修饰：要想…… → To find an ideal job in this big company 置首；良好的 → good；同时（两者）→ both ... and
第⑤步  检查：both...and 连接的两个名词对称；an ideal job 冠词
译文  To find an ideal job in this big company, you must have both good English skills and the ability to work as part of a team.
```

易错点："团队合作精神"直译 teamwork spirit 是硬伤，绕道 the ability to work as part of a team 或 teamwork skills 更地道——词汇绕道技术下一课细讲。

</details>
