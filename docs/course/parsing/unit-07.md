title: 第 7 课 · 非谓语动词：doing · done · to do 当配件
---

> ⏱ 预计 4~6 小时，建议拆 3 天 ｜ 前置：[第 6 课](./unit-06.md) ｜ 难度：B1+（拆句课）

## 本课目标

学完这课，你将能：

- [ ] 拆句时一眼把 doing / done / to do 标记为"配件"，不再错数谓语
- [ ] 把后置定语（the man standing there / a book written by...）还原成定语从句再翻译
- [ ] 用"找主句主语"判断法，秒分分词状语该主动还是被动
- [ ] 认出 with 复合结构并整块剥掉，让主干现形

## 核心方法

**先记住一句话：非谓语是"配件"，不是"谓语"。**

数谓语的时候，看到 doing / done / to do 一律先别数——先验明正身。

**三形态速览**

| 形态 | 底层味道 | 一秒例子 |
|---|---|---|
| to do | 目的、将来 | I came here to learn English. |
| doing | 主动、进行 | the man standing there（人自己站着）|
| done | 被动、完成 | a book written by a farmer（书是"被写"的）|

**拆句三步**

1. 圈出句中所有 V-ing / V-ed / to do
2. 验明正身：谓语 = 有时态、和主语配合的那个动词。它前面若已有真谓语，后面的 -ing / -ed / to do 全是配件
3. 归类挂到主干上：后置定语 / 状语 / 宾补 / with 复合结构

**配件用法逐个看**

```
① 后置定语：the man standing there      → 还原 the man who is standing there
           a book written by a farmer → 还原 a book which was written by a farmer
   还原成定语从句，再按第 4 课套路翻译（"的"字前置）

② 状语（句首最多）：Seeing the police, he ran.    → he 主动"看见" → doing
                  Seen from the hill, the town... → town 被"看" → done
   逻辑主语判断法：找主句主语——它主动发出动作用 doing，被动作作用用 done

③ 宾补：I saw him cross the street（看到全程）/ crossing（看到正在进行）
   拆句时整体当宾语的"补语配件"，不当谓语

④ with 复合结构：with + 名词 + doing/done/形/介短，整块是"背景板"状语
   例：With the exam coming, ... / He slept with the light on.
   拆句时整块剥掉，主干立刻现形
```

**分词状语翻译技巧**：句首分词常译"一……就 / ……之后 / ……时"；被动的加"被/受到"或直接转主动。

## 例句拆解示范

例 1（日常 · doing 后置定语）

```
原句  The man standing at the gate is my uncle.
切分  [The man (standing at the gate)] [is【谓】 my uncle]
      └─ doing 后置定语 ─────┘    └─ 谓语 + 表语 ─┘
主干  The man is my uncle
配件  standing at the gate → 后置定语，还原 who is standing at the gate
直译  （正站在大门口的）那个男人是我的叔叔
调整  站在大门口的那个人是我叔叔
```

例 2（职场 · done 后置定语）

```
原句  The report written by the new employee impressed everyone.
切分  [The report (written by the new employee)] [impressed【谓】 everyone]
      └─ done 后置定语 ─────────┘      └─ 谓语 + 宾语 ─┘
主干  The report impressed everyone
配件  written by the new employee → 后置定语，还原 which was written by...
直译  （由那位新员工写的）报告给每个人留下了深刻印象
调整  新员工写的那份报告，让所有人都眼前一亮
```

例 3（日常 · doing 状语）

```
原句  Hearing the good news, she called her mother at once.
切分  [(Hearing the good news),] [she] [called【谓】 her mother] [at once]
      └ doing 状语，主语 she 主动"听到" ┘  └─ 谓 + 宾 ─┘ └状语┘
主干  She called her mother
配件  Hearing the good news → 时间/原因状语；at once → 时间状语
直译  （听到这个好消息），她立刻打电话给她的妈妈
调整  一听到这个好消息，她马上给妈妈打了电话
```

例 4（科普 · done 状语）

```
原句  Seen from space, our planet looks like a shining blue ball.
切分  [(Seen from space),] [our planet] [looks【谓】 like a shining blue ball]
      └ done 状语，主语 planet 是"被看"的 ┘ └─ 谓语 ──────────┘
主干  Our planet looks like a ball
配件  Seen from space → 被动状语（"被从太空看"）；shining → doing 前置定语
直译  （从太空被看），我们的行星看起来像一个闪光的蓝色球体
调整  从太空望去，地球就像一颗闪亮的蓝色圆球
```

例 5（日常 · with 复合结构）

```
原句  With the window open and the light on, the old man fell asleep in his chair.
切分  [(With the window open and the light on),] [the old man] [fell asleep【谓】] [in his chair]
      └ with 复合结构：背景板，整块剥掉 ──────┘  └─ 谓语 ─┘  └ 地点状语┘
主干  The old man fell asleep
配件  with the window open and the light on → 伴随状语；in his chair → 地点状语
直译  （窗户开着、灯亮着），老人在椅子里睡着了
调整  窗户开着，灯也亮着，老人就在椅子上睡着了
```

## 中文学习者常见误区

| ❌ 误区 | ✅ 正确做法 | 为什么 |
|---|---|---|
| 数谓语时把 standing / written 也数进去，一句数出两三个"谓语" | 谓语只有带时态、和主语配合的那一个；其余 -ing / -ed / to do 全是配件 | 一根线只穿一颗顶梁柱珠子，配件挂上去就行，不能冒充柱子 |
| 读 Seen from the hill, we can see... 读得云里雾里 | 先找主句主语再判主动被动：主语"被看"用 done，主语"主动看"用 seeing | 分词的逻辑主语默认是主句主语，两者对不上，句子就"皮球踢不动" |
| the man standing there 译成"站着那个男人" | 还原成 who is standing there，再"的"字前置："正站在那儿的那个男人" | 中文定语一律前置；先还原成从句，翻译就接上了第 4 课的老路 |
| 把句首 to do 当"将要发生的谓语"硬读 | to do 在主语/宾语位置就是名词配件：To learn English well takes time → 学好英语（这件事）需要时间 | 非谓语可以扮演名词、形容词、副词，位置决定角色，就是不扮演谓语 |

## 实战练习

每句走完整五步：原句 → 切分 → 主干 → 配件 → 直译/调整。

热身（找回手感）

1. The girl sitting next to me is from Chengdu.
2. I have a lot of homework to finish tonight.
3. The letters written in ink have faded.

标准（本课主力）

4. Not knowing the answer, he kept silent.
5. Given more time, we could do much better.
6. The teacher asked us to hand in the papers before Friday.
7. With the exam coming, the library is full every night.

挑战（考试级长度，模拟句）

8. Bitten twice, the postman now refuses to enter the yard where the dog lives.
9. The road built last year connects the two villages that used to be cut off by the river.
10. Standing on the mountaintop and looking at the clouds below, he finally understood why his father loved this place so much.

<details><summary>热身 · 参考答案（先自己拆完再点开）</summary>

**1.**

```
原句  The girl sitting next to me is from Chengdu.
切分  [The girl (sitting next to me)] [is【谓】 from Chengdu]
      └ doing 后置定语 ───┘    └─ 谓语 + 表语 ─┘
主干  The girl is from Chengdu
配件  sitting next to me → 后置定语，还原 who is sitting next to me
直译  （坐在我旁边的）女孩来自成都
调整  坐在我旁边的那个女孩是成都人
```

**2.**

```
原句  I have a lot of homework to finish tonight.
切分  [I] [have【谓】 a lot of homework] [(to finish tonight)]
      └主谓┘└── 宾语 ──┘   └ to do 后置定语 ─┘
主干  I have a lot of homework
配件  to finish tonight → to do 后置定语（今晚要完成的）
直译  我有很多（今晚要完成的）作业
调整  我今晚有一大堆作业要做
```

**3.**

```
原句  The letters written in ink have faded.
切分  [The letters (written in ink)] [have faded【谓】]
      └ done 后置定语 ─┘      └─ 谓语 ─┘
主干  The letters have faded
配件  written in ink → 后置定语（信是"被写"的）
直译  （用墨水写的）那些信已经褪色了
调整  那些用墨水写的信，字迹已经褪色了
```

**4.**

```
原句  Not knowing the answer, he kept silent.
切分  [(Not knowing the answer),] [he] [kept【谓】 silent]
      └ doing 状语，he 主动"不知道" ┘  └主谓┘└表语┘
主干  He kept silent

**5.**

```
原句  Given more time, we could do much better.
切分  [(Given more time),] [we] [could do【谓】 much better]
      └ done 状语，we 被"给" ┘  └─ 谓语 ─┘
主干  We could do much better
配件  Given more time → 条件状语（被动：如果"被给"更多时间）
直译  （被给更多时间），我们能做得好得多
调整  如果多给我们一点时间，我们可以做得好得多
```

**6.**

```
原句  The teacher asked us to hand in the papers before Friday.
切分  [The teacher asked【谓】 us] [(to hand in the papers before Friday)]
      └──── 主谓 + 宾语 ────┘  └ to do 宾补 ──────────┘
主干  The teacher asked us to do sth
配件  to hand in the papers → 宾补；before Friday → 时间状语
直译  老师要求我们（在周五前交论文）
调整  老师让我们周五之前把论文交上去
```

主干  The library is full
配件  With the exam coming → with 复合结构作原因状语；every night → 时间状语
直译  （随着考试来临），图书馆每晚都是满的
调整  考试临近，图书馆每天晚上都座无虚席

**8.**

```
原句  Bitten twice, the postman now refuses to enter the yard where the dog lives.
切分  [(Bitten twice),] [the postman] [refuses【谓】] [(to enter the yard (where the dog lives))]
      └ done 状语，邮递员被"咬" ┘ └ 主语 ┘ └─ 谓语 ─┘└ 宾补 + 定语从句 ─┘
主干  The postman refuses to enter the yard
配件  Bitten twice → done 原因状语；where the dog lives → 定语从句修饰 yard；now
直译  （被咬过两次），邮递员现在拒绝进入（那只狗住的）院子
调整  被咬过两次之后，邮递员现在说什么也不肯进那个有狗的院子了
```

**9.**

```
原句  The road built last year connects the two villages that used to be cut off by the river.
切分  [The road (built last year)] [connects【谓】] [the two villages (that used to be cut off by the river)]
      └ done 后置定语 ─┘      └─ 谓语 ─┘ └─ 宾语 + 定语从句 ─────────┘
主干  The road connects the two villages
配件  built last year → 后置定语；that used to be cut off by the river → 定语从句
直译  （去年修建的）这条路连接了（曾经被河流隔断的）两个村庄
调整  这条去年新修的路，把两个过去被大河隔开的村子连了起来
```

**10.**

```
原句  Standing on the mountaintop and looking at the clouds below, he finally understood why his father loved this place so much.
切分  [(Standing on the mountaintop and looking at the clouds below),] [he finally understood【谓】] [(why his father loved this place so much)]
      └ 两个 doing 并列作状语，he 主动"站、看" ──────┘  └─ 谓语 ─┘  └─ 宾语从句 ─┘
主干  He finally understood (宾语从句)
配件  Standing...and looking... → 并列伴随状语；finally；从句内 so much 状语
直译  （站在山顶上、看着脚下的云），他终于明白了（为什么他父亲这么爱这个地方）
调整  他站在山顶，望着脚下的云海，终于明白父亲为什么那么热爱这个地方了
