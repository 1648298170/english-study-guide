> ⏱ 预计 4~6 小时，建议拆成 3 天完成 | 前置：[第 3 课 · 并列结构](./unit-03.md) | 难度：B1+（拆句课）

从句刀口第一站：定语从句。考试阅读里最吓人的长句，八成是被一层层定语从句喂胖的。规则你都学过——本课只解决两件事：**3 秒识别**（包括 that 消失的情况），以及**三种译法怎么选**。学完这课，"从句套从句"对你来说只是洋葱的两层。

## 本课目标

- [ ] 能 3 秒识别定语从句，并说出先行词是谁
- [ ] 能识破 that 被省略的定语从句
- [ ] 会用决策树在前置法、后置法、融合法中选对译法
- [ ] 能拆解"从句套从句"的嵌套结构（先内后外）
- [ ] 能完整拆解考研风格模拟长句，译文不硬译

## 核心方法

### 识别：引导词总表

| 引导词 | 指代谁 | 例 |
| --- | --- | --- |
| who | 人（作主语） | the man who called you |
| whom | 人（作宾语，书面） | the man whom I met |
| which | 物 | the book which I read |
| that | 人 / 物皆可 | the book that changed my life |
| whose | 谁的（所属） | the girl whose father works here |
| where | 地点（= in which） | the city where I was born |
| when | 时间（= on which） | the day when we first met |
| why | 原因（= for which） | the reason why he left |

识别三步：**找引导词 → 回头找先行词（它前面最近的名词）→ 验证从句是否在回答"哪一个 / 什么样的"**。是，就是定语从句。

### that 消失术：缺宾语就是定从

引导词在从句中作宾语时，可以被省略——这是长难句里最常见的"隐身术"：

```
原句  The book I read last week was about space.
分析  The book [I read ___ last week] → read 后面缺宾语！
      → I read ___ last week 是定语从句，引导词 that/which 被省略，指 the book
信号  名词后面直接跟上"人称主语 + 动词"，中间没有引导词
      （两个主语相撞：book ∥ I）→ 九成是省略了引导词的定语从句
```

一句话口诀：**名词后紧跟主谓，缺谁谁就是引导词。**

### 三种译法决策树

语法课教你"什么是定语从句"，这棵树教你"翻译时怎么办"：

```
定语从句有多长？
│
├─ ≤ 8 词（短）
│    └─ 前置法：译成"……的"，放到先行词前面
│         The girl (who called you) is my sister.
│         → 给你打电话的那个女孩是我妹妹
│
├─ > 8 词（长）
│    └─ 后置法：另起一句，重复先行词
│         "……，这个报告……" / "……，它……"
│         例：The team published a report (that pointed out three serious
│         problems in the city's old transport system).
│         → 团队发表了一份报告，报告指出了该市老旧交通系统的三个严重问题
│
└─ There be 句型
     └─ 融合法：从句和主句熔成一句，不译"的"
          There are many students (who like this song).
          → 很多学生喜欢这首歌。（不是"有很多喜欢这首歌的学生"）
```

为什么长从句不前置？"的"字串太长会窒息：*写了一份指出该市老旧交通系统三个严重问题的报告的团队*——读到结尾，读者已经断气。后置法是中文给长定语准备的呼吸机。

### 嵌套定语从句：先内后外

从句里再套从句时，处理顺序是**先做内层成品，再套外层**——像剥洋葱的反向操作：

```
原句  the professor (who wrote the report (that attracted attention))
第 1 步（内层）that attracted attention → 修饰 report
      内层成品：引起关注的【那份报告】
第 2 步（外层）who wrote 【那份报告】→ 修饰 professor
      外层成品：写了那份报告的【那位教授】
```

翻译嵌套从句，先在小黑板上把每层成品做好，再往主句里装。

### 判断卡壳时：它到底是定语从句还是状语从句？

看它修饰谁：修饰名词 = 定语从句；修饰动词 = 状语从句。同一个 where，身份完全不同：

```
定从  I remember the house (where I grew up).      → 修饰 house：哪座房子
状从  I cried (where the two roads met).           → 修饰 cried：在哪里哭
```

第 5 课会正面进攻状语从句，这里先埋个路标。

## 例句拆解示范

### 示范 1 · 热身（日常场景 · 10 词 · 前置法）

```
原句  The woman who lives next door is a famous doctor.
切分  [The woman (who lives next door)] [is a famous doctor.]
      └─ 主语 + 定语从句 ───────┘ └─ 谓语 + 表语 ─────┘
主干  the woman 【谓语】is a doctor
配件  (who lives next door) → 定语从句，修饰 woman（4 词 ≤ 8 → 前置法）
      famous → 定语，修饰 doctor
直译  那个女人（住在隔壁的）是一位著名的医生。
调整  住在隔壁的那位女士是一位名医。
```

看点：从句只有 4 词，稳稳前置。注意 lives 有 -s——它是从句内的真谓语，但只对 woman 负责。

### 示范 2 · 标准（日常场景 · 13 词 · that 省略识别）

```
原句  The camera (that) my uncle gave me for my birthday takes great photos.
切分  [The camera ((that) my uncle gave me for my birthday)] [takes great photos.]
      └─ 主语 + 省略引导词的定语从句 ────────────────┘ └─ 谓语 + 宾语 ────┘
主干  the camera 【谓语】takes photos
配件  ((that) my uncle gave me for my birthday) → 定语从句，修饰 camera
      识别：camera 后紧跟 my uncle（主谓）→ 定从信号
            gave 缺直接宾语 → 省略的 that 指 camera，作 gave 的宾语
      (for my birthday) → 从句内原因状语
      great → 定语，修饰 photos
直译  那台相机（我叔叔生日时送我的）拍很棒的照片。
调整  我生日时叔叔送我的那台相机，拍照效果特别好。
```

看点：全句真谓语两个（gave / takes），gave 缺宾语——省略的 that 正是补上缺口的引导词。

### 示范 3 · 标准（科普/新闻风格 · 19 词 · 后置法）

```
原句  The scientist made an important discovery that could change the treatment of several common diseases in the near future.
切分  [The scientist] [made] [an important discovery (that could change the treatment (of several common diseases) (in the near future)).]
      └─ 主语 ────┘ └谓语┘ └─ 宾语 + 长定语从句 ──────────────────────────┘
主干  the scientist 【谓语】made a discovery
配件  important → 定语，修饰 discovery
      (that could change the treatment...) → 定语从句，修饰 discovery
      ★ 从句 13 词 > 8 → 后置法
      (of several common diseases) → 定语，修饰 treatment
      (in the near future) → 从句内时间状语
直译  那位科学家做出了一项重要发现（可能改变若干常见疾病的治疗的、在不久的将来）。
调整  这位科学家取得了一项重要发现，它可能在不久的将来改变多种常见疾病的治疗方式。
```

看点：长从句硬塞前置就是直译版的下场。后置法用"它"另起一句，句子立刻能呼吸。

### 示范 4 · 标准（校园场景 · 14 词 · 融合法）

```
原句  There are many students who find it hard to speak English confidently in public.
切分  [There are many students (who find it hard to speak English confidently in public).]
      └─ There be 句型 + 定语从句 ───────────────────────────────┘
主干  there 【谓语】are students（There be 句型）
配件  many → 定语，修饰 students
      (who find it hard to...) → 定语从句，修饰 students → 融合法：不译"的"
      confidently → 方式状语；in public → 地点状语（均在从句内）
直译  有很多学生（他们觉得很难在公开场合自信地说英语）。
调整  很多学生觉得，很难在公开场合自信地说英语。
```

看点：融合法把 There be 和从句熔成一句自然的中文——"有……的人……"直接写成"……的人……"。

### 示范 5 · 挑战（考研风格模拟句① · 25 词 · 嵌套定从）

```
原句  The professor who wrote the report that attracted so much public attention
      last week has refused to give any interviews to the media so far.

切分  [The professor (who wrote the report (that attracted so much public attention last week))]
      └─ 主语 + 嵌套定语从句（两层）──────────────────────────────┘
      [has refused] [to give any interviews (to the media)] [so far].
      └─ 谓语 ──┘ └─ 宾语 ───────────┘ └时间状语┘

主干  the professor 【谓语】has refused
      （主语太长？先整包放下，主干动词在很后面——这正是本句的杀伤力）
配件  嵌套从句，先内后外：
      内层 (that attracted so much public attention last week) → 定语从句，修饰 report
        内层成品：上周引起巨大公众关注的【那份报告】
      外层 (who wrote the report...) → 定语从句，修饰 professor
        外层成品：撰写那份报告的【那位教授】
      (to the media) → 对象状语
      so far → 时间状语
直译  那位教授（写了那份报告（上周吸引了很多公众关注的））到目前为止拒绝接受任何媒体的采访。
调整  那份报告上周引起巨大关注，而撰写报告的教授至今拒绝接受任何媒体采访。
```

看点：谓语 has refused 离主语隔了 14 个词——主谓分离是长难句第一杀手。救法：先把定从整包放下，直奔动词。

### 示范 6 · 挑战（考研风格模拟句② · 26 词 · 宾从 + 双定从）

```
原句  Anyone who has worked in a big company knows that the rules which seem
      strange at first often exist for reasons that nobody remembers any more.

切分  [Anyone (who has worked in a big company)] [knows] [(that) the rules
      └─ 主语 + 定从① ────────────────┘ └谓语┘ └─ 宾语从句 ─────────
      (which seem strange at first) often exist (for reasons (that nobody remembers any more)).]
      └─ 定从②，修饰 rules ──────┘          └─ 定从③，修饰 reasons ────┘

主干  主句 anyone 【谓语】knows + 宾从
      宾从主干 the rules 【谓语】exist
配件  (who has worked in a big company) → 定语从句①，修饰 anyone（6 词 → 前置）
      (that) → 宾语从句引导词
      (which seem strange at first) → 定语从句②，修饰 rules（4 词 → 前置）
      at first → 从句内时间状语
      often → 频率状语
      (for reasons that...) → 原因状语
      (that nobody remembers any more) → 定语从句③，修饰 reasons（5 词 → 前置）
直译  任何人（在大公司工作过的）都知道，（那些起初看起来奇怪的）规则常常因为（没人再记得的）原因而存在。
调整  在大公司待过的人都懂：那些乍看奇怪的规矩，往往有着谁也记不清的来历。
```

看点：全句 5 个谓语（has worked / knows / seem / exist / remembers），三层从句（定从 + 宾从 + 宾从内再挂两个定从）。每个从句单独看都只是 B1 水平——难的从来不是从句，是套娃。

## 中文学习者常见误区

| ❌ 错误做法 | ✅ 正确做法 | 为什么 |
| --- | --- | --- |
| 见 which 就慌，当成疑问词"哪个" | 定从里的 which 是关系词，替代先行词 | which 在这里不提问，只是把两句话缝在一起的那根线 |
| 所有定从都硬塞"……的"放前面 | 短从句前置，长从句后置另起一句 | 中文"的"字串超过十几个字就读不动了——给读者留口气 |
| 先行词找最近的名词 | 从句读完，往回找真正被修饰的名词 | 被从句隔开后，最近的名词不一定是真先行词（尤其嵌套时） |
| that 省略时认不出从句 | 名词后紧跟"主谓"= 定从信号 | The book I read... 里 book 和 I 两个主语相撞，必有一层从句 |
| where/when 从句一律当状语从句 | 先问修饰谁：修饰名词 = 定从，修饰动词 = 状从 | the city where... 是"哪座城"；...where we waited 是"在哪等" |

## 实战练习

任务统一：按五步法完整拆解（原句 → 切分 → 主干 → 配件 → 直译/调整）。每个定语从句请额外标注：①先行词 ②选用的译法（前置 / 后置 / 融合）及理由。

**热身**

1. The girl who is singing on the stage is my cousin.
2. I still remember the day when we first met.
3. The bag (that) you bought last week looks great.

**标准**

4. This is the small Italian restaurant where we celebrated our tenth wedding anniversary last year.
5. The engineer whose design won the award now leads a team of twenty people in the company.
6. The phone (that) I bought online arrived two days later than the seller had promised.
7. The government has introduced a new policy that aims to reduce air pollution in major cities within the next five years.

**挑战**

8. The teacher who had taught the course for more than ten years decided to rewrite the textbook that most schools in the area were still using.
9. There is a growing number of young people who prefer jobs that allow them to work from home rather than in a traditional office.
10. The success of the experiment, which surprised many experts in the field, has opened a door that scientists had tried to open for decades.

**1.**

```
原句  The girl who is singing on the stage is my cousin.
切分  [The girl (who is singing on the stage)] [is my cousin.]
      └─ 主语 + 定语从句 ──────────┘ └─ 谓语 + 表语 ─┘
主干  the girl 【谓语】is my cousin
配件  (who is singing on the stage) → 定语从句，修饰 girl
      先行词 girl；从句 6 词 ≤ 8 → 前置法
      (on the stage) → 从句内地点状语
直译  那个女孩（正在台上唱歌的）是我的表妹。
调整  台上正在唱歌的那个女孩是我表妹。
```

**2.**

```
原句  I still remember the day when we first met.
切分  [I still remember] [the day (when we first met).]
      └─ 主干 ────────┘ └─ 宾语 + 定语从句 ─┘
主干  I 【谓语】remember the day
配件  still → 状语
      (when we first met) → 定语从句，修饰 day
      先行词 day；when = on which；从句 4 词 → 前置法
      first → 从句内状语
直译  我仍然记得那一天（我们第一次相遇的）。
调整  我仍记得我们初次相遇的那一天。
```

看点：when 引导但修饰 the day（名词）→ 定语从句，不是时间状语从句。验证：它在回答"哪一天"。

**3.**

```
原句  The bag (that) you bought last week looks great.
切分  [The bag ((that) you bought last week)] [looks great.]
      └─ 主语 + 省略引导词的定语从句 ────────┘ └谓语+表语┘
主干  the bag 【谓语】looks great
配件  ((that) you bought last week) → 定语从句，修饰 bag
      识别：bag 后紧跟 you（主谓相撞）→ 定从信号
            bought 缺宾语 → 省略的 that 指 bag，作 bought 的宾语
      last week → 从句内时间状语
直译  那个包（你上周买的）看起来很棒。
调整  你上周买的那个包很好看。
```

**4.**

```
原句  This is the small Italian restaurant where we celebrated our tenth wedding anniversary last year.
切分  [This is] [the small Italian restaurant (where we celebrated our tenth wedding anniversary last year).]
      └─主干┘ └─ 表语 + 定语从句 ──────────────────────────────┘
主干  this 【谓语】is the restaurant
配件  small / Italian → 定语，修饰 restaurant
      (where we celebrated our tenth wedding anniversary last year) → 定语从句，修饰 restaurant
      先行词 restaurant；where = in which；从句 10 词 > 8 → 后置法
      last year → 从句内时间状语
直译  这就是那家小意大利餐馆（我们去年在那里庆祝结婚十周年的）。
调整  就是这家小意大利餐馆——我们去年在这里庆祝了结婚十周年。
```

看点：10 词从句已到后置法临界区。若强行前置："我们去年庆祝结婚十周年的那家小意大利餐馆"也还能读——但再加两个词就该后置了。临界句两法皆可，长句只许后置。

原句  The engineer whose design won the award now leads a team of twenty people in the company.
切分  [The engineer (whose design won the award)] [now leads] [a team (of twenty people) (in the company).]
      └─ 主语 + 定语从句 ────────────┘ └─谓语┘ └─ 宾语 + 定语 ──────┘
主干  the engineer 【谓语】leads a team
配件  (whose design won the award) → 定语从句，修饰 engineer
      先行词 engineer；whose design = 他的设计；从句 5 词 → 前置法

      (of twenty people) → 定语，修饰 team
      (in the company) → 定语，修饰 team
直译  那位工程师（他的设计得了奖的）现在领导一个二十人的团队（公司里的）。
调整  那位设计获奖的工程师，现在带领公司里一个二十人的团队。

原句  The phone (that) I bought online arrived two days later than the seller had promised.

主干  the phone 【谓语】arrived
配件  ((that) I bought online) → 定语从句，修饰 phone
      识别：phone 后紧跟 I → 定从信号；bought 缺宾语 → that 省略
      (online) → 从句内方式状语
      (two days) → 程度状语

直译  那部手机（我网上买的）到得比卖家承诺的晚了两天。

原句  The government has introduced a new policy that aims to reduce air pollution in major cities within the next five years.
切分  [The government] [has introduced] [a new policy (that aims to reduce air pollution (in major cities) (within the next five years)).]
      └─ 主语 ────┘ └─ 谓语 ────┘ └─ 宾语 + 长定语从句 ────────────────────────┘
主干  the government 【谓语】has introduced a policy
配件  new → 定语，修饰 policy
      (that aims to reduce...) → 定语从句，修饰 policy
      先行词 policy；从句 14 词 > 8 → 后置法
      (in major cities) → 从句内地点状语
      (within the next five years) → 从句内时间状语
直译  政府已经推出一项新政策（旨在减少空气污染、在主要城市、在未来五年内的）。

```

切分  [The teacher (who had taught the course for more than ten years)] [decided to rewrite]
      └─ 主语 + 定语从句 ────────────────────────────┘ └─ 谓语 ─────┘
      [the textbook (that most schools (in the area) were still using).]
      └─ 宾语 + 定语从句 ────────────────────────────┘

主干  the teacher 【谓语】decided to rewrite the textbook
配件  (who had taught the course for more than ten years) → 定语从句，修饰 teacher
      先行词 teacher；从句 10 词 → 前置偏长，可前置亦可拆短句（参考：前置"教这门课十多年的那位老师"尚可读）
      for more than ten years → 从句内时间状语
      (that most schools in the area were still using) → 定语从句，修饰 textbook
      先行词 textbook；从句 8 词 → 前置法（"本地区多数学校仍在用的"）
      (in the area) → 定语，修饰 schools
直译  那位老师（教这门课十多年的）决定重写那本教科书（本地区大多数学校仍在使用的）。
调整  教这门课十多年的老师决定，重写本地区多数学校仍在使用的那本教材。
```

**9.**

```
原句  There is a growing number of young people who prefer jobs that allow them to work from home rather than in a traditional office.
切分  [There is a growing number of young people (who prefer jobs (that allow them to work from home (rather than in a traditional office))).]
      └─ There be 句型 ───────────────── 嵌套两层定语从句 ────────────────────┘
主干  there 【谓语】is a number of people（There be 句型 → 融合法候选）
配件  growing → 定语，修饰 number
      (who prefer jobs...) → 定语从句①，修饰 people（→ 融合）
      (that allow them to work from home...) → 定语从句②，修饰 jobs（嵌套在①内，→ 前置）
      (rather than in a traditional office) → 从句内对比状语
直译  有一个不断增长的数字的年轻人（他们更喜欢允许他们在家而不是在传统办公室工作的职位）。
调整  越来越多的年轻人更喜欢能在家办公的工作，而不是坐传统办公室。
```

看点：融合法 + 内嵌前置法组合出击：外层 people 从句熔掉"的"，内层 jobs 从句（7 词）前置。

**10.**

```
原句  The success of the experiment, which surprised many experts in the field, has opened a door that scientists had tried to open for decades.
切分  [The success (of the experiment), (which surprised many experts (in the field)),] [has opened]
      └─ 主语 + 定语 + 非限定定从（插入语）────────────────────┘ └─ 谓语 ──┘
      [a door (that scientists had tried to open for decades).]
      └─ 宾语 + 定语从句 ───────────────────────┘

主干  the success 【谓语】has opened a door
配件  (of the experiment) → 定语，修饰 success
      (which surprised many experts in the field) → 非限定性定语从句（逗号隔开），修饰 the success
      ★ 双逗号插入语：拆句时先整包搬走，主干立刻露出 —— success...has opened a door
      (in the field) → 定语，修饰 experts
      (that scientists had tried to open for decades) → 定语从句，修饰 door（9 词 → 前置/后置皆可）
      for decades → 从句内时间状语
直译  那项实验的成功（这让该领域许多专家感到惊讶）打开了一扇门（科学家们几十年来一直试图打开的）。
调整  实验的成功让该领域许多专家大跌眼镜，而它推开的正是科学家们几十年都没能推开的那扇门。
```

看点：非限定性定从（, which...）是天然的"插入语包"。手术顺序：先搬走双逗号包 → 找主干 → 再回来处理从句。这是考研阅读的高频句式。

</details>
