## 本课目标

学完这一课，你可以做到：

- [ ] 用 should / shouldn't 给出温和的建议
- [ ] 分清 must（说话人的强烈要求）和 have to（外部规定）
- [ ] 准确区分 mustn't（禁止）和 don't have to（不必），不再说反
- [ ] 认识 should have done（本该做而没做），听懂别人的"事后提醒"

## 语法讲解

这一课的主角是情态动词（modal verb，放在动词前面表示"建议、必须、许可"等语气的词，后面永远接动词原形）。should、must、have to 长得像，脾气可完全不同。

### 第一步：should + 动词原形，温和的建议

- **You look tired. You should rest.** 你看起来累了，应该休息。
- **You shouldn't eat so much junk food.** 你不该吃那么多垃圾食品。
- **Should I take the medicine before meals?** 我应该饭前吃药吗？
- 回答：**Yes, you should.** / **No, you shouldn't.**

should 的语气是"我建议，听不听随你"。记住它后面永远接动词原形：没有 to，也没有第三人称变化。

### 第二步：must + 动词原形，说话人的强烈要求

must 也是"必须"，但这个"必须"来自**说话人自己**，语气比 should 重得多。

- **You must see a doctor.** 你必须去看医生。（说话人态度非常坚决）
- **You must finish it today.** 你必须今天完成。

### 第三步：have to + 动词原形，外部规定的必须

have to 的"必须"来自**外部规则或客观情况**，不是说话人的态度。

- **I have to work on Saturday.** 我周六得上班。（公司规定，不是我愿意）
- **She has to wear a uniform at work.** 她上班必须穿制服。

三兄弟放一起看：

| | 谁说了算 | 语气 | 例句 |
| ---- | ---- | ---- | ---- |
| should | 说话人给建议 | 温和 | You should rest. |
| must | 说话人强烈要求 | 很强 | You must rest now. |
| have to | 外部规则 | 客观必须 | I have to work on Saturday. |

### 第四步：重头戏，mustn't 与 don't have to 是反义词

| | 意思 | 心里话 |
| ---- | ---- | ---- |
| mustn't | 禁止（不许做） | Don't do it! |
| don't have to | 不必（没必要做） | You can do it or not. It's OK. |

- **You mustn't smoke here.** 这里禁止吸烟。（做不得）
- **You don't have to come early tomorrow.** 明天你不必来早。（来早也行，不早来也行）

记法：mustn't 是"门关死"，don't have to 是"门开着，随你"。这两个词说反了，意思会完全颠倒，务必分清。

### 第五步：轻带一笔，should have done

should have + 过去分词，表示**本该做而没做**，带一点后悔或责备。

- **You look sick. You should have seen a doctor yesterday.** 你看起来病了，昨天就该去看医生的。（实际没去）
- **I should have studied harder.** 我本该更努力学习的。（实际上没有）

现在只要能听懂、看懂这个结构就够了，后面课程还会正式见面。

## 中文母语者常见错误

| ❌ 错误说法 | ✅ 正确说法 | 为什么 |
| ---- | ---- | ---- |
| You should to rest. | You should rest. | 情态动词后接动词原形，中间不加 to。 |
| He musts finish it today. | He must finish it today. | must 没有第三人称变化，任何人称都是 must。 |
| Should I to take this medicine? | Should I take this medicine? | 疑问句同样守规矩：should + 动词原形。 |
| You mustn't come tomorrow. It's a holiday.（想说"不必来"） | You don't have to come tomorrow. | mustn't 是"禁止"；"不必"要说 don't have to，两者意思相反。 |
| I must work last Saturday. | I had to work last Saturday. | must 没有"过去式"，说过去的"不得不"要用 had to。 |

## 练习

**第一组 · 填空：按括号提示用 should / must / have to 的正确形式填空（第 1~5 题）**

1. （给建议）You look tired. You ______ go to bed early.
2. （外部规定）I ______ wear a uniform at work.
3. （说话人强烈要求）It's dangerous! You ______ stop right now!
4. （不必要）Tomorrow is Sunday. You ______ get up early.
5. （禁止）You ______ smoke in the hospital.

**第二组 · 选择（第 6~9 题）**

6. You ______ eat so much junk food. It's bad for you.  A. shouldn't  B. don't have to
7. It's a rule. Students ______ use phones in class.  A. mustn't  B. don't have to
8. Today is a holiday, so she ______ go to work.  A. mustn't  B. doesn't have to
9. You ______ tell anyone. It's a secret.  A. mustn't  B. don't have to

**第三组 · 改错：每句有一处错误，写出正确句子（第 10~12 题）**

10. You should to take this medicine twice a day.
11. He musts finish the report today.
12. I must work last Saturday, so I missed the trip.

**第四组 · 中译英（第 13~16 题）**

13. 你应该多锻炼。
14. 你发烧了，必须去看医生。
15. 我明天不得不加班。
16. 这里禁止吸烟。

**第五组 · 情景改写（第 17~18 题）**

17. 你的朋友没休息好，现在病得很重。用 should have done 说一句"事后提醒"。
18. 妈妈对孩子说"不许再看手机了"，用 mustn't 翻译这句话。

## 今日任务

1. **写作**：给一位"总熬夜的朋友"写 4 句建议，should、shouldn't、must、don't have to 各用一次。
2. **写作二（轻量）**：用 should have done 写 2 句"本周本该做而没做"的事，对自己诚实一点。
3. **录音**：朗读你的两段建议，模仿坚定的语气说 must、mustn't，温和的语气说 should。
4. **观察练习**：找出生活或工作中 3 条真实规则（比如公司规定、地铁标识），用 have to 或 mustn't 各写下来。
