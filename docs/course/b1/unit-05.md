## 语法讲解

上一课的第一条件句说"很可能发生的事"，这一课的第二条件句（second conditional）正好相反：**现在或将来的想象，可能性很小，甚至根本不可能**。语法上它叫虚拟语气（subjunctive，表示假设、与事实相反的情形）。别被名字吓到，它只有两条公式。

### 第一步：基本结构

| 从句（想象的条件） | 主句（想象的结果） |
| ---- | ---- |
| If + 一般过去式 | would / wouldn't + 动词原形 |

- **If I had a car, I would drive to work.** 如果我有车，我就开车上班。（现实：我没有车）
- **If she knew the answer, she would tell us.** 如果她知道答案，她会告诉我们的。（现实：她不知道）
- **If I didn't live so far away, I would walk to work.** 如果我住得不这么远，我就走路上班了。（现实：住得远）

特别注意：从句用了过去式，说的却**不是过去的事**，而是"现在或将来的想象"。过去式在这里是"虚拟信号"，意思是"不是真的"。

### 第二步：If I were you，be 动词的特殊待遇

虚拟条件句里，be 动词各人称一律用 **were**（正式、标准的用法）。口语里 If I was 也听得到，但书面语和考试请统一用 were。

- **If I were you, I would take the job.** 如果我是你，我就接受这份工作。
- **If he were here, he would help us.** 如果他在这里，他会帮我们的。

缩写要认识：I would = **I'd**；you would = you'd；he/she would = he'd/she'd；we/they would = we'd/they'd。

- **If I were you, I'd say sorry.** 如果我是你，我就去道歉。

### 第三步：肯定与否定

- **If I had more free time, I would learn the guitar.** 如果我有更多空闲时间，我就学吉他。
- **If I weren't so busy, I would go with you.** 如果我没这么忙，我就和你一起去。
- **If I lived near the office, I wouldn't get up so early.** 如果我住得离公司近，就不用起这么早了。

### 第四步：中文母语者专属难点，动词要"后退一步"

中文说"如果我有时间，我就去"，动词"有"和"去"从来不变形，全靠"如果"二字表达假设。英语偏要让动词"后退一步"变成过去式，用形式告诉对方"这不是真的"。

| 想表达的意思 | 真实版本（我觉得会发生） | 想象版本（可能性很小） |
| ---- | ---- | ---- |
| 如果我有时间，我就去 | If I have time, I will go. | If I had time, I would go. |
| 如果明天是晴天，我们就去公园 | If it is sunny tomorrow, we will go to the park. | If it were sunny tomorrow, we would go to the park.（明知明天多半不是晴天） |

判断时机：说这句话时你心里认为"很可能发生"，用第一条件句；心里认为"只是想想，基本没戏"，用第二条件句。

## 中文母语者常见错误

| ❌ 错误说法 | ✅ 正确说法 | 为什么 |
| ---- | ---- | ---- |
| If I will have time tomorrow, I will go with you.（只是想象） | If I had time, I would go with you. | 想象、不太可能的情形用第二条件句：从句过去式，主句 would。 |
| If I was you, I would take the job. | If I were you, I would take the job. | 虚拟条件句里 be 动词统一用 were（口语 was 常见，但书面和考试用 were）。 |
| If I would have money, I would travel. | If I had money, I would travel. | would 只住主句；从句用过去式。 |
| If I have time tonight, I would call you. | If I have time, I will call you. 或 If I had time, I would call you. | 真实和虚拟不能混搭，前后"时态表情"要一致。 |
| If I am you, I would rest. | If I were you, I would rest. | 中文"如果我是你"动词不变形，英语必须"退一步"：虚拟用 were，不用 am / is。 |

## 练习

**第一组 · 填空：用括号里动词的正确形式填空（第 1~5 题）**

1. If I ______ (have) more time, I would learn the guitar.
2. If she ______ (know) his number, she would call him.
3. If I ______ (be) you, I would accept the job.
4. He would help us if he ______ (be) here.
5. If we ______ (not / work) tomorrow, we would go to the beach.

**第二组 · 选择（第 6~9 题）**

6. If I ______ a million dollars, I would buy a big house for my parents.  A. have  B. had
7. If I were you, I ______ say sorry to her.  A. will  B. would
8. What ______ you do if you were the boss?  A. would  B. will
9. I'm busy today. If I were free, I ______ shopping with you.  A. went  B. would go

**第三组 · 改错：每句有一处错误，写出正确句子（第 10~12 题）**

10. If I will have enough money, I will travel around the world.（只是想象）
11. If I was you, I would tell the teacher.
12. If I would know the answer, I would tell you.

**第四组 · 中译英（第 13~16 题）**

13. 如果我是你，我会早点睡觉。
14. 如果我有一百万美元，我会辞职去旅行。
15. 如果他会开车，他就不会坐公交车上班了。
16. 如果我住得离公司近一点，我就不用起这么早了。

**第五组 · 情景改写（第 17~18 题）**

17. 把事实改成想象：I don't have a car, so I can't pick you up.（用 if...would...）
18. 朋友因为太累想辞职，请用 If I were you 给他一条建议。

## 今日任务

1. **写作一**：以 If I had a million dollars 开头，连续写 5 句想象，用上生词表里的 quit、charity、dream 至少一次。
2. **写作二**：写 3 条 If I were you, I would... 给朋友（或给拖延的自己）的建议。
3. **录音**：朗读两段写作内容，注意 I'd 的发音 /aɪd/，别读成两个词。
4. **对比练习**：挑一个"如果"，分别写真实版和虚拟版，体会动词"后退一步"的感觉，比如 If I have time tonight, I will call you. / If I had time, I would call you.
