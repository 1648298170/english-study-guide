> **难度：C1（精进期）** | 对应[学习框架阶段 5](../../guide/stage-5.md) | 前置：[B2 课程](../b2/index.md) | 全程预计 **12~18 个月**（累计约 1200 小时）

恭喜你走到这里。能开始 C1 的人，英语早已不是障碍，而是工具。这门课要解决的问题是：**你的英语"能用"，但还不够"精准自然"**。

## 这门课是什么

C1 课程对应框架的阶段 5「精进期」，核心定位一句话：**从"能用"到"精准自然"，去掉字幕与词典两根拐杖。**

| 项目 | 说明 |
| --- | --- |
| 课程规模 | 7 课，每课一个学习循环约 3 周（学 1 周 + 练 1 周 + 用 1 周） |
| 总时长 | 12~18 个月，累计投入约 1200 小时 |
| 词汇目标 | 累计 6,000~8,000 接受性词汇（其中主动词汇 8,000 中的精华部分要能用于写作口语） |
| 语法内容 | C1 级修辞语法：倒装、分裂句、省略与替代、名词化、语域控制、模糊限制语与话语标记 |
| 最大的变化 | 输入靠生肉，输出靠改写。B2 及以前在"学英语"，C1 开始在"打磨英语" |

B2 毕业时，你能舒适地看剧、工作、聊天。C1 要追求的是下一层：同样一个意思，你能挑出**最准确、最得体、最像母语者**的那一种说法。别人一听你说英语，反应从"你英语挺好的"变成"你在国外待过很多年吧"。

## 上课程式（C1 版）

每一课都走这四步，顺序不能乱：

1. **通读**。先把整课讲解通读一遍，例句全部朗读出声。C1 的语法点不再是"规则"，而是"风格选择"，读出声才有语感。
2. **外刊找例证**。学完每个语法点，去 The Economist、The Atlantic 的文章里找 2~3 个真实例句，抄进你的"证据本"。找不到例证的结构，说明它低频，低频就少用。
3. **改写练习**。这是 C1 的核心动作。把平淡的句子改写成倒装、分裂句、名词化、语域升级的版本，一题一题写，别只在脑子里过。
4. **写作任务必经批改**。每课的写作任务写完必须批改：真人老师、语伴或 AI 都行，但必须有第二双眼睛。不批改的写作等于白写，这是框架从 B2 起就反复强调的规矩，C1 阶段一次都不能省。

## 与框架配合（阶段 5 每周模板）

课程负责"学懂"，框架负责"进度与材料"。两条线并行，每周节奏如下：

| 每周动作 | 频次 | 与本课程的配合 |
| --- | --- | --- |
| 去字幕三步走 | 每天 | 影视从双语字幕 → 纯英文字幕 → 无字幕，逐级升档；本课程生词在外刊与影视中反复偶遇 |
| 外刊精读 | 每周 2 篇 | 每课"今日任务"里的外刊精读就在这里做；找语法例证、抄 hedging 例句 |
| 真人课纠错 | 每周 1 次 | 要求教师逐句记录你的错误并复盘，重点纠语域与用词 |
| 语言交换 | 每周 1~2 次 | HelloTalk / Tandem 找长期伙伴；把每课学的话语标记用到真实对话里 |
| 写作 | 每周 300~500 词 | 完成各课写作任务，体裁扩展：议论文、正式邮件、报告 |

词汇方面，阶段 5 不再刷词表：转向词根体系化 + 语境猜词 + 按职业兴趣建领域卡组。低频词从大量输入中自然积累，课程生词表只是引子。

## 课程目录

| 课次 | 主题 | 内容一句话 |
| --- | --- | --- |
| [第 1 课 · 倒装：让强调更有力](./unit-01.md) | 倒装 | Never have I... / Not only did...，把重点推到句首 |
| [第 2 课 · 分裂句：就是它](./unit-02.md) | 分裂句 | It was... that...，精准聚焦你想强调的成分 |
| [第 3 课 · 省略与替代：不说重复的话](./unit-03.md) | 省略与替代 | so do I / one / does，让句子干净利落 |
| [第 4 课 · 名词化：正式文体的引擎](./unit-04.md) | 名词化 | decide → decision，正式文体的核心机关 |
| [第 5 课 · 语域控制：正式与非正式](./unit-05.md) | 语域 | 同一个意思，三种场合，三副面孔 |
| [第 6 课 · 模糊限制语与话语标记](./unit-06.md) | hedging 与话语标记 | 不把话说死的艺术，组织话语的路标 |
| [第 7 课 · C1 综合复习与毕业自测](./unit-07.md) | 总复习 | 六课串成一套拳，对照框架阶段 5 毕业自查 |

建议顺序：1 → 2 → 3 → 4 是"句子武器库"，5 → 6 是"场合与分寸"，7 是总检验。前四课是后三课的地基，别跳。

## 学完之后

- 前置：[B2 课程](../b2/index.md)（如果你还没学完）
- 之后：[阶段 6 精通期](../../guide/stage-6.md)。C1 毕业后没有下一门"课程"了，英语从此成为生活的一部分：读原版书、看生肉、用英文工作思考，错误靠定期"审计"而不是靠教材。

准备好了就从[第 1 课](./unit-01.md)开始，或者继续你学到的那一课。
