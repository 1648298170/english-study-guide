> 框架是**地图**，课程是**车**。《英语学习框架》告诉你学多久、用什么材料、如何进阶；这里的课程则手把手教你**每一个知识点**——中文讲解、生词表、练习题、答案解析，零基础也能自己学懂。

## 现在就可以上的课

### 🗣️ [启蒙课 · 音标与自然拼读](./stage0/)

**给谁上**：完全零基础，字母都认不全的你（对应[阶段 0](/guide/stage-0)）

**学什么**：26 个字母、全部 48 个音素的发音要领（每个音都讲清"嘴怎么放、中文相近音差在哪"）、自然拼读规则——看到生词能拼、听到音能写。

**多久**：9 课，1~2 周

### 📘 [A1 课程 · 入门英语](./a1/)

**给谁上**：完成启蒙课（或已认识音标）的你（对应[阶段 1](/guide/stage-1)）

**学什么**：be 动词 → 代词 → 单复数 → there be → 一般现在时 → can → 疑问句 → 数字时间，9 课打完 A1 全部语法地基，每课带生词表、中文母语者错误对照、15+ 道练习和答案。

**多久**：9 课 × 约 1 周 = 2~3 个月（与 Anki 词汇打卡并行，见下方"课程怎么上"）

### 📗 [A2 课程 · 积累期](./a2/)

**给谁上**：A1 毕业的你（对应[阶段 2](/guide/stage-2)）

**学什么**：现在进行时 → 一般过去时（规则+不规则）→ will vs be going to → 频率副词 → 可数不可数 → 比较级最高级 → 介词，9 课把时间轴从"现在"扩展到"过去与未来"。

**多久**：9 课 × 约 1~2 周 = 4~6 个月（目标累计 2,000 词）

### 📙 [B1 课程 · 成长期](./b1/)

**给谁上**：A2 毕业的你（对应[阶段 3](/guide/stage-3)）

**学什么**：现在完成时（两课重点攻坚）→ 过去进行时 → 条件句一二级 → 情态 → 连词 → 不定式 vs 动名词 → 短语动词 → 定语从句，11 课——B1 是整条路线最大的一道坎，慢即是快。

**多久**：11 课 × 约 1~2 周 = 8~12 个月（目标累计 3,000 词，同期开始开口说）

### 📕 [B2 课程 · 突破期](./b2/)

**给谁上**：B1 毕业的你（对应[阶段 4](/guide/stage-4)）

**学什么**：过去完成时 → 第三条件句 → 间接引语 → 被动语态 → 推测情态 → 冠词系统 → 高级不定式动名词，8 课——这是决定"哑巴英语"命运的阶段，语法开始为输出服务。

**多久**：8 课 × 约 2 周 = 10~14 个月（目标累计 4,500+ 词，真人对话上量）

### 📓 [C1 课程 · 精进期](./c1/)

**给谁上**：B2 毕业的你（对应[阶段 5](/guide/stage-5)）

**学什么**：倒装 → 分裂句 → 省略与替代 → 名词化 → 语域控制 → hedging 与话语标记，7 课——从"能用"到"精准自然"，学的是母语者的修辞工具箱。

**多久**：7 课 × 约 3 周 = 12~18 个月（目标累计 6,000~8,000 词）

## 课程怎么上（重要，先读一遍）

每节课的固定流程：

1. **通读讲解**——像看老师板书一样，例句出声读
2. **生词录入**——把生词表录入 Anki / 不背单词，当天开始按算法复习
3. **做题对答案**——目标 **≥90 分**；达不到就 3 天后重做一遍
4. **完成今日任务**——每课末尾的 3~5 条行动项（跟读、录音、写作）
5. **周末复盘**——重看本周两课的"常见错误"表，错误读 3 遍

## 课程与框架如何配合

| 课程负责 | 框架负责 |
|---|---|
| 每个知识点的讲解与练习 | 学多久、用什么材料、何时进阶 |
| 中文母语者错误纠正 | 每周学习时间怎么分配（每周模板） |
| 课堂内的基础词汇（约 150~200 词） | 阶段词汇总量目标（阶段 1 共 1,000 词，差额靠 Anki 刷高频卡组） |

**一句话**：白天按框架的每周模板执行，其中"学教材"的时段换成本课程；课程毕业标准即框架阶段毕业标准。

## 常见问题

**Q：课程里没有发音音频怎么办？**
每课生词和例句，用有道词典 / 欧路词典 App 查词点读，跟读模仿——这也是框架推荐的日常习惯（见[阶段 0](/guide/stage-0)）。

**Q：六门课要一口气全学完吗？**
不用，也千万别。启蒙 + A1 + A2 + B1 + B2 + C1 对应框架阶段 0~5，按顺序学、学完一门对照框架毕业标准再进下一门。A2 起你还应同步使用 English Pod、VOA 等外部输入（框架各阶段已排好）——课程管"学懂"，输入管"学会"。

**Q：课上学不懂某一课怎么办？**
正常。回上一课确认前置知识 → 重读讲解 → 只重做该课练习。连换 3 个思路还不懂的内容，记到学习日志，继续往下学（多数疑问会在后面课程的应用中突然打通）。
