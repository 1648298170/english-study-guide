> 框架是**地图**，课程是**车**。《英语学习框架》告诉你学多久、用什么材料、如何进阶；这里的课程则手把手教你**每一个知识点**——中文讲解、生词表、练习题、答案解析，零基础也能自己学懂。

## 现在就可以上的课

### 🗣️ [启蒙课 · 音标与自然拼读](./stage0/)

**给谁上**：完全零基础，字母都认不全的你（对应[阶段 0](/guide/stage-0)）

**学什么**：26 个字母、全部 48 个音素的发音要领（每个音都讲清"嘴怎么放、中文相近音差在哪"）、自然拼读规则——看到生词能拼、听到音能写。

**多久**：9 课，1~2 周

### 📘 [A1 课程 · 入门英语](./a1/)

**给谁上**：完成启蒙课（或已认识音标）的你（对应[阶段 1](/guide/stage-1)）

**学什么**：be 动词 → 代词 → 单复数 → there be → 一般现在时 → can → 疑问句 → 数字时间，9 课打完 A1 全部语法地基，每课带生词表、中文母语者错误对照、15+ 道练习和答案。

**多久**：9 课 × 约 1 周 = 2~3 个月（与 Anki 词汇打卡并行，见下方"课程怎么上"）

## 课程怎么上（重要，先读一遍）

每节课的固定流程：

1. **通读讲解**——像看老师板书一样，例句出声读
2. **生词录入**——把生词表录入 Anki / 不背单词，当天开始按算法复习
3. **做题对答案**——目标 **≥90 分**；达不到就 3 天后重做一遍
4. **完成今日任务**——每课末尾的 3~5 条行动项（跟读、录音、写作）
5. **周末复盘**——重看本周两课的"常见错误"表，错误读 3 遍

## 课程与框架如何配合

| 课程负责 | 框架负责 |
|---|---|
| 每个知识点的讲解与练习 | 学多久、用什么材料、何时进阶 |
| 中文母语者错误纠正 | 每周学习时间怎么分配（每周模板） |
| 课堂内的基础词汇（约 150~200 词） | 阶段词汇总量目标（阶段 1 共 1,000 词，差额靠 Anki 刷高频卡组） |

**一句话**：白天按框架的每周模板执行，其中"学教材"的时段换成本课程；课程毕业标准即框架阶段毕业标准。

## 常见问题

**Q：课程里没有发音音频怎么办？**
每课生词和例句，用有道词典 / 欧路词典 App 查词点读，跟读模仿——这也是框架推荐的日常习惯（见[阶段 0](/guide/stage-0)）。

**Q：A2 及以后的课程呢？**
启蒙课 + A1 是零基础最难的"冷启动"段，先吃透这两门。A2 课程会按同样模板陆续上线；A2 起你也已具备使用 English Pod、VOA 等外部课程的能力（框架阶段 2 已排好）。

**Q：课上学不懂某一课怎么办？**
正常。回上一课确认前置知识 → 重读讲解 → 只重做该课练习。连换 3 个思路还不懂的内容，记到学习日志，继续往下学（多数疑问会在后面课程的应用中突然打通）。
